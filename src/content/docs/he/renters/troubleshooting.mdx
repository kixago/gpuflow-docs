## שגיאות API

כשמשהו משתבש, ה-API עונה עם קוד שגיאה. חפשו את ה-`code` בתשובה:

```json
{ "error": { "message": "...", "type": "server_error", "code": "provider_offline" } }
```

| סטטוס | `code` | מה זה אומר | מה לעשות |
| --- | --- | --- | --- |
| 401 | `invalid_api_key` | המפתח חסר, הוקלד לא נכון, הוחלף באמצעות **מפתח חדש**, או שההשכרה הסתיימה. | העתיקו את המפתח שוב. בדקו שהכותרת היא `Authorization: Bearer gfk_…`. אם ההשכרה הסתיימה, התחילו השכרה חדשה. |
| 400 | `invalid_body` | מה ששלחתם הוא לא JSON תקין. | בדקו את המירכאות והפסיקים. הדוגמאות בדף [שימוש במפתח ה-API](/he/renters/api-quickstart/) הן נקודת התחלה טובה. |
| 503 | `provider_offline` | המכונה של הספק מנותקת כרגע. | חכו דקה ונסו שוב. אם היא נשארת מנותקת 10 דקות, ההשכרה מסתיימת מעצמה ומשלמים רק עד הרגע שבו היא התנתקה. |
| 503 | `relay_unreachable` | GPUFlow לא הצליח להגיע לחיבור של המכונה. | נסו שוב בעוד רגע. אם זה חוזר, פתחו פנייה לתמיכה. |
| 502 | `provider_error` | המכונה החזירה תשובה ריקה. | נסו שוב. אם זה חוזר, דווחו על ההשכרה. |
| 503 | `provider_unbound` | המפתח שלכם לא מקושר ל-GPU. | פתחו פנייה לתמיכה. |

**"model … not found":** ביקשתם מודל שאין על המכונה. הריצו את בדיקת `/v1/models` מהדף [שימוש במפתח ה-API](/he/renters/api-quickstart/) והשתמשו בשם שמופיע שם.

## הוספת קרדיטים

| הודעה | פתרון |
| --- | --- |
| אמתו את כתובת האימייל שלכם לפני הוספת קרדיטים. | פתחו את האימייל מ-GPUFlow ולחצו על הקישור. לא קיבלתם אימייל? לחצו על **שליחת האימייל מחדש** בפס הצהוב בלוח המחוונים, ובדקו בתיקיית הספאם. |
| הזינו סכום בין $10 ל-$500. | כל טעינה חייבת להיות בין $10 ל-$500. |
| התשלום בוטל. לא חויבתם. | יצאתם מהדף של Stripe לפני התשלום. נסו שוב. |
| שילמתם, אבל הקרדיטים לא מופיעים | חכו דקה ורעננו את הדף. עדיין כלום אחרי 10 דקות? פתחו פנייה לתמיכה. |

## התחלת השכרה

| הודעה | פתרון |
| --- | --- |
| אין מספיק קרדיטים: נדרשים … | הוסיפו קרדיטים, או שכרו לפחות שעות. |
| המכונה של ה-GPU הזה מנותקת כרגע. | בחרו GPU אחר, או לחצו על **הודע לי כשיחזור להיות מחובר** בכרטיס שלו כדי לקבל אימייל כשהוא חוזר. |
| בחרו בין … ל-… שעות. | ל-GPU הזה יש מינימום ומקסימום שעות משלו. בחרו מספר ביניהם. |
| זו המודעה שלכם. | אי אפשר לשכור את ה-GPU של עצמכם. |
| יותר מדי ניסיונות. נסו שוב בעוד שעה. | חכו שעה. המגבלה הזו מגינה על חשבונות מסקריפטים שיצאו משליטה. |

## עדיין תקועים?

פתחו פנייה בכתובת [gpuflow.app/support](https://gpuflow.app/he/support). אם מדובר בהשכרה מסוימת, השתמשו ב-**דיווח על בעיה** שלידה, כדי שנדע באיזו השכרה מדובר. צרפו את ה-`code` של השגיאה, את השעה שבה זה קרה, ואם אפשר, את הפקודה או הקוד שהרצתם (**בלי מפתח ה-API שלכם**).
