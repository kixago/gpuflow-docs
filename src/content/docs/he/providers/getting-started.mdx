מריצים **פקודה אחת** על המחשב שבו נמצא ה-GPU. היא מתקינה את כל מה שצריך, מחברת את המחשב ל-GPUFlow ושומרת עליו מחובר. לא צריך Docker או SSH, ולא פותחים שום פורט בראוטר.

## מה צריך

- מחשב עם **Linux 64 ביט ו-systemd**. Ubuntu, Debian, Fedora, Arch, openSUSE וההפצות הקרובות אליהן עובדות כולן. גם מחשבים רגילים (x86_64) וגם ARM (arm64) מתאימים.
- GPU. **NVIDIA היא האפשרות שנבדקה.** כרטיסי AMD עובדים דרך התמיכה של Ollama ב-ROCm, אבל לוח המחוונים עדיין לא מציג פרטים על GPU של AMD.
- הרשאה להשתמש ב-`sudo` במחשב הזה.
- חשבון GPUFlow. [פתחו חשבון כאן](https://gpuflow.app/he/join). אמתו גם את כתובת האימייל; תצטרכו אותה כדי לקבל תשלום.

<Aside>
עדיין אין מתקין ל-Windows או ל-macOS.
</Aside>

## 1. העתקת פקודת ההתקנה

<Steps>

1. פתחו את **לוח מחוונים** ולחצו על **המכונות שלי** בתפריט מימין.
2. תחת **הוספת GPU בפקודה אחת**, השאירו את **למה משמשת המכונה הזו?** על **מודעה חדשה (להגדרה אחרי שתתחבר)**.
3. לחצו על **העתקה** ליד הפקודה.

</Steps>

<Image src={addMachine} alt="המכונות שלי: תיבת הפקודה וכפתור ההעתקה שלה מסומנים" />

הפקודה נראית כך (בפקודה שלכם יופיע בסוף הטוקן שלכם):

```bash
curl -fsSL https://gpuflow.app/downloads/install.sh | sudo bash -s -- --token eyJhbGciOi...
```

<Aside type="caution" title="השתמשו בה תוך 15 דקות">
הטוקן שבפקודה תקף ל-15 דקות בלבד. אם מופיע `enrollment failed` והלוג אומר שתוקף הטוקן פג, רעננו את לוח המחוונים והעתיקו פקודה חדשה.
</Aside>

## 2. הרצת הפקודה במחשב עם ה-GPU

<Steps>

1. במחשב עם ה-GPU, פתחו טרמינל.
2. הדביקו את הפקודה והקישו Enter. אם `sudo` מבקש סיסמה, הקלידו אותה.
3. חכו לשורה הזו:

   ```
   Enrolled. gpuflow-agent is running.
   ```

   מהרגע הזה המחשב שלכם מחובר. אחר כך המתקין מוריד מודל AI, וזה יכול לקחת כמה דקות בפעם הראשונה.

</Steps>

## 3. יצירת המודעה

בחזרה בדף **המכונות שלי**, המחשב שלכם מופיע עכשיו כ-**מקוון** עם ההודעה **המכונה הזו מחוברת אך לא מפורסמת.**

<Image src={notListed} alt="כרטיס של מכונה מחוברת שלא פורסמה, עם כפתור הפרסום להשכרה מסומן" />

לחצו על **פרסום להשכרה**. טופס המודעה נפתח כשהמכונה הזו כבר נבחרה. מלאו את השם, דגם ה-GPU והמחיר לשעה, ולחצו על **הוסף GPU**.

לא בטוחים מה לכתוב או כמה לגבות? ראו [כתיבת מודעה טובה](/he/providers/creating-listings/) ו-[איך לתמחר את ה-GPU שלכם](/he/providers/pricing/).

## 4. בדיקה שהמודעה פעילה

פתחו את **ה-GPU שלי**. המודעה שלכם מציגה את המכונה עם נקודה ירוקה. עכשיו היא מופיעה בשוק, ושוכרים יכולים לשכור אותה.

<Image src={myGpus} alt="ה-GPU שלי: מודעה שהמכונה שלה מחוברת, עם כפתור העריכה מסומן" />

## דרכים אחרות

**קודם המודעה:** לחצו על **הוסף GPU**, מלאו את הטופס והשאירו את **מכונה** על **ללא, לקשר מאוחר יותר**. בדף **ה-GPU שלי**, לחצו על **העבר למצב מקוון** מתחת למודעה. תקבלו פקודה שמקשרת את המחשב *למודעה הזו*, כך שאחר כך אין מה לקשר.

**מחשב מופיע כלא מקוון:** לכל מחשב מנותק בדף **המכונות שלי** יש פקודה משלו, ישר על הכרטיס. הריצו אותה על המחשב הזה. היא מתקינה מחדש את הסוכן ומחזירה **את אותה מכונה**, כך שהמודעה שלה חוזרת לפעול ולא נוצר כפיל. תמיד בטוח להריץ פקודה מלוח המחוונים פעמיים על אותו מחשב.

## בחירת מודל AI

שוכרים משתמשים ב-GPU שלכם דרך מודלי AI שרצים עליו. כברירת מחדל המתקין מוריד את `qwen2.5:7b`. כדי לבחור מודל אחר, הוסיפו `--model` בסוף הפקודה:

```bash
curl -fsSL https://gpuflow.app/downloads/install.sh | sudo bash -s -- --token <your token> --model llama3.1:8b
```

בחירות נפוצות, מהקטן לגדול: `qwen2.5:0.5b`, `deepseek-r1:1.5b`, `qwen2.5:7b`, `deepseek-r1:7b`, `llama3.1:8b`, `qwen2.5:14b`. המודל חייב להיכנס בזיכרון של ה-GPU (VRAM), אז לכרטיסים קטנים בחרו מודל קטן.

כדי להוסיף מודל מאוחר יותר במחשב שכבר מחובר, לא צריך טוקן חדש:

```bash
curl -fsSL https://gpuflow.app/downloads/install.sh | sudo bash -s -- --model qwen2.5:14b
```

כבר מריצים שרת משלכם שתואם OpenAI? הוסיפו `--engine none --ollama-url http://127.0.0.1:<port>`.

<Aside type="tip">
כתבו בתיאור המודעה אילו מודלים אתם מגישים. שוכרים מחפשים אותם שם.
</Aside>

## מעקב אחרי המכונה

```bash
systemctl status gpuflow-agent      # is it running?
journalctl -u gpuflow-agent -f      # live log (Ctrl+C to stop)
```

הסוכן מפעיל את עצמו מחדש אחרי קריסה או הפעלה מחדש של המחשב. הוא יוצר רק חיבורים **יוצאים**, אל `gpuflow.app` ואל `ws.gpuflow.app`, ולכן הוא עובד מאחורי כל ראוטר ביתי בלי הפניית פורטים.

## נתונים חיים

כל כרטיס מכונה בדף **המכונות שלי** מציג, עם עדכון כל 15 שניות:

- **מהירות (בנצ'מרק):** טוקנים לשנייה לכל אחד מהמודלים שלכם, כפי שנמדדו על המכונה שלכם. הסוכן בודק מודל פעם אחת כשהוא מופיע ושוב כל יום, אבל רק כשאף אחד לא השתמש במכונה במשך 5 דקות. שוכר תמיד קוטע את הבדיקה.
- **שירות לשוכרים:** מהירות אמיתית וזמן עד הטוקן הראשון, מהשכרות אמיתיות.
- **GPU:** טמפרטורה, עומס, VRAM, צריכת חשמל, מאוורר, מהירויות שעון, חיבור PCIe.
- **מערכת ומודלים:** טמפרטורה ועומס של ה-CPU, RAM, מערכת ההפעלה, זמן פעילות, המודלים המותקנים, והמודל שטעון כרגע.

רק אתם רואים את הנתונים האלה.

## על מה תקבלו הודעה

תקבלו **אימייל והתראה** (הפעמון בראש האתר) כש:

- **ה-GPU שלכם מושכר,**
- **שוכר מחכה** ל-GPU שלכם בזמן שהוא מנותק (לכל היותר פעם ביום לכל GPU). הפעילו את המכונה כדי לקבל את ההשכרה.
- **משיכה נשלחה,** או לא עברה.

תקבלו **התראה** כשהשכרה מסתיימת, עם הסכום שהרווחתם, וכשהכנסות הופכות לזמינות למשיכה.
