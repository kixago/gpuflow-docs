GPUFlow では、借りるときに使う名前とプロバイダーとして使う名前を分けて扱うため、両方が同じ人のものだと他の人にはわかりません。メールアドレスと本名が表示されることはありません。名前はすべて **アカウント設定 → あなたの名前** で設定します。

## ユーザー名

<Tip id="names.username">

ユーザー名はサインインに使い（メールアドレスでも可）、表示名をオンにしない限り、レビューの横に表示される名前になります。長さは %names.usernameMin%〜%names.usernameMax% 文字で、使えるのは a〜z の英字、数字、そしてその間に 1 つずつ入るドット、アンダースコア、ハイフンです。大文字と小文字は区別されません。

</Tip>

- ユーザー名はアカウント作成時に決めます。Google または GitHub で登録した場合は、次のステップで決めます。
- 誰でも読んで入力できるよう、ユーザー名はどの言語でもラテン文字を使います。

## 表示名

<Tip id="names.display">

表示名は任意です。オンにすると、レビューの横にユーザー名の代わりに表示されます。どの言語でもよく、ほかの人と同じでもかまいません。

</Tip>

## プロバイダー名とページのアドレス

<Tip id="names.provider">

GPU を出品すると、借り手に見えるのはプロバイダー名で、ユーザー名が見えることはありません。プロバイダーページは gpuflow.app/marketplace/provider/ のあとにページのアドレスが続く URL にあります。どのアカウントにも最初は「Quiet Falcon」のようなランダムなプロバイダー名が付いていて、いつでも変更できます。

</Tip>

- プロバイダー名とページのアドレスは、ユーザー名や、借り手として書いたレビューとはつながっていません。
- プロバイダーページには、出品中の GPU、提供者レベル、借り手からのレビューが表示されます。

## 名前の変更

<Tip id="names.changes">

ユーザー名とページのアドレスは %names.changeDays% 日に 1 回変更できます。以前のユーザー名やアドレスは %names.oldNameHoldDays% 日間あなたのために確保され、ほかの人は使えません。その間は以前のアドレスへのリンクも引き続き使えます。

</Tip>

## 表示されないもの

- メールアドレス。
- 本名。サインインに使う Google や GitHub のアカウント名も表示されません。
- Google や GitHub のプロフィール写真。全員に同じシンプルなアイコンが表示されます。
- どの借り手名とどのプロバイダー名が同じアカウントのものか。
