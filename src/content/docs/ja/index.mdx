## GPUFlow とは

GPUFlow は、人から人へ GPU を時間単位で貸し借りするマーケットプレイスです。

- **借り手**は、カードでクレジットを追加し、GPU を選び、その GPU 用の API キーを受け取ります。このキーは、OpenAI API に対応したアプリやコードならどれでも使えます。
- **プロバイダー**は、GPU を搭載した Linux コンピューターでコマンドを 1 つ実行し、1 時間あたりの料金を決めます。報酬は銀行口座に支払われます。
