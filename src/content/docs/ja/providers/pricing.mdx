借り手があなたの GPU を選ぶか、ほかの人の GPU を選ぶか。いちばん大きな決め手は価格です。ここでは、あなたの手取り、動かすのにかかる費用、そして同じような GPU の現在のレンタル相場を説明します。

## あなたの手取り

1 時間あたりの料金はあなたが決めます。借り手は、使った時間の分だけその料金を支払います。**GPUFlow が 12% を受け取り、あなたの手取りは 88% です。**

| 1 時間あたりの料金 | 1 時間あたりの収益 | 1 日 8 時間 × 30 日 |
| --- | --- | --- |
| $0.10 | $0.088 | $21.12 |
| $0.20 | $0.176 | $42.24 |
| $0.35 | $0.308 | $73.92 |
| $0.50 | $0.44 | $105.60 |

最後の列は、GPU が毎日 8 時間レンタルされた場合の額です。実際にどれだけ使われるかは、価格、選んだモデル、オンラインにしている頻度によって変わります。

## 動かすのにかかる費用

主な費用は電気代です。1 分で計算できます。

<Steps>

1. GPU が使われているときに **マイマシン** を開きます。カードの **電力** に、消費電力がワット単位で表示されています。
2. 1,000 で割ってキロワットにします。350 W なら 0.35 kW です。
3. 1 kWh あたりの電気料金を掛けます（電気料金の明細に書かれています）。

</Steps>

例: 0.35 kW × 1 kWh あたり $0.15 = **1 時間あたり $0.053**。1 時間あたりの収益は、これを十分に上回るようにしてください。

## 現在のレンタル相場

以下は、**2026 年 9 月**にほかの GPU レンタルサイトで調べた、GPU 1 台・1 時間あたりのオンデマンド価格です。調べたのは Vast.ai、RunPod、Salad、SimplePod、TensorDock、Hyperstack、Lambda で、一部は比較サイトの getdeploying.com を通じて確認しました。価格は毎週変わるので、決まりではなく目安として使ってください。

| GPU | 1 時間あたりの一般的な価格 |
| --- | --- |
| RTX 3060 12 GB | $0.05 – $0.08 |
| RTX 3070 | $0.09 – $0.13 |
| RTX 3080 | $0.14 – $0.17 |
| RTX 3090 | $0.11 – $0.31 |
| RTX 4060 Ti 16 GB | $0.10 – $0.14 |
| RTX 4070 | $0.07 – $0.15 |
| RTX 4070 Ti | $0.19 – $0.24 |
| RTX 4080 | $0.23 – $0.27 |
| RTX 4090 | $0.30 – $0.46 |
| RTX 5080 | $0.22 – $0.39 |
| RTX 5090 | $0.41 – $0.69 |
| RTX A4000 | $0.08 – $0.17 |
| RTX A5000 | $0.16 – $0.25 |
| RTX A6000 | $0.40 – $0.53 |

大手クラウド企業のデータセンター向け GPU は、もっと高額です。たとえば AWS の NVIDIA L4 は、1 台で 1 時間約 $0.80 です。ただし、GPUFlow のようなマーケットプレイスに来る借り手は、AWS ではなく上の表の価格とあなたを比べます。

<Aside type="note" title="価格帯の下半分から始める理由">
それらのサイトの多くでは、借り手はマシン全体を借ります。GPUFlow で借り手が使えるのは、API を通じたあなたの AI モデルです。借り手にとっては手軽ですが、できることは限られます。そのため、少なくとも最初の数件のレンタルが入るまでは、価格帯の下半分に設定してください。
</Aside>

## 出品フォームの価格バー

**GPUを出品** または **編集** で時間料金を入力すると、入力欄の下のバーに、あなたの価格がどのあたりにあるかが表示されます。

<Image src={bar} alt="「時間料金」欄の下にある価格バー。この GPU として標準的な価格であることが表示されている" />

- **緑色の帯「他のレンタルサイト」:** ほかのレンタルサイトでの、あなたの GPU モデルの一般的な価格帯です。上の表の値です。
- **青い線「このモデルの他の GPUFlow 出品」:** 同じ GPU モデルのほかの GPUFlow 出品の平均価格と、その最低価格・最高価格です。該当する出品があるときだけ表示されます。
- **オレンジ色の印:** あなたの価格です。バーの下の行には **安め**、**標準的な価格**、**高め** のいずれかが表示されます。最後の行には、12% の手数料を引いた 1 時間あたりの収益が表示されます。

あなたの GPU が表になく、GPUFlow でほかに誰も出品していない場合、バーは比較できません。表の中でいちばん近いカードを目安にしてください。

## 価格の決め方: かんたんな手順

<Steps>

1. **低めから始めます。** あなたの GPU の価格帯のうち、下から 3 分の 1 の範囲で価格を選びます。RTX 4090 なら $0.30 – $0.35 くらいです。
2. **オンラインを保ちます。** オフラインの GPU は借りられません。数セントの差より、オンラインにしている時間のほうが大切です。
3. **1 週間後に見直します。**
   - ほとんどの時間レンタルされている場合は、$0.02 – $0.05 値上げします。
   - まったくレンタルされない場合は、$0.02 – $0.05 値下げします。説明欄にモデル名が書かれているかも確認してください。
4. **月に一度確認します。** ほかのサイトの価格は変わります。価格は **マイGPU → 編集** で変更できます。

</Steps>
