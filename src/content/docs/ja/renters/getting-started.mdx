GPUFlow で GPU を借りるのにかかる時間は、5 分ほどです。必要なのはメールアドレスと支払い用のカードだけです。

**受け取れるもの:** 1 台の GPU 用の API キーです。使えるのは、あなたが選んだ時間だけです。このキーは OpenAI のキーと同じように使えるので、OpenAI API に対応したアプリやスクリプトならどれでも利用できます。ログインするサーバーはなく、インストールするものもありません。

## 1. アカウントを作成する

<Steps>

1. [gpuflow.app](https://gpuflow.app/ja/join) を開き、右上の **サインアップ** をクリックします。
2. ユーザー名、メールアドレス、パスワード（2 回）を入力します。
3. **アカウント作成** をクリックします。

</Steps>

<Image src={signup} alt="アカウント作成フォーム。ユーザー名、メールアドレス、パスワードの欄と「アカウント作成」ボタンが強調表示されている" />

パスワードを作る代わりに、**Google で続ける** または **GitHub で続ける** をクリックすることもできます。

## 2. メールアドレスを確認する

GPUFlow からすぐにメールが届きます。メールを開き、中のリンクをクリックしてください。

<Aside type="caution">
メールアドレスの確認が済むまで、クレジットは追加できません。数分たってもメールが届かない場合は、迷惑メールフォルダーを確認するか、ダッシュボード上部の黄色いバナーにある **メールを再送信** をクリックしてください。
</Aside>

## 3. クレジットを追加する

レンタル料金はクレジットで支払います。**1 クレジット = $0.01** なので、$25 で 2,500 クレジットになります。

<Steps>

1. **ダッシュボード** を開き、左のメニューにある **支払い** をクリックします。
2. **クレジットを追加** で金額をクリックするか、金額を入力します。1 回に追加できるのは $10〜$500 です。手数料はかかりません。
3. **支払いへ進む** をクリックします。決済パートナーの Stripe のページに移動するので、カードで支払います。
4. 支払いが終わると GPUFlow に戻ります。1 分以内に、支払いページの上部と、ヘッダーのオレンジ色のボタンにクレジットが表示されます。

</Steps>

<Image src={credits} alt="支払いページ。金額ボタンと「支払いへ進む」ボタンが強調表示されている" />

## 4. GPU を選ぶ

どのページでも、上部の **GPUを閲覧** をクリックします。今すぐ使える GPU は、緑色の **即時アクセス可能** の欄にあります。

<Image src={market} alt="マーケットプレイス。GPU のカード 1 枚と、その「今すぐレンタル」ボタンが強調表示されている" />

各カードで次の点を確認してください。

- **1 時間あたりの料金。** 1 時間使うとこの金額がかかります。
- **VRAM。** 大きな AI モデルほど多くの VRAM が必要です。目安として、7B モデルは 8 GB 以上、14B モデルは 16 GB 以上あれば快適に動きます。
- **モデル。** GPU の名前をクリックすると、その GPU のページが開きます。プロバイダーは、提供している AI モデル（例: `qwen2.5:7b`）を説明欄に書いています。

決めたら **今すぐレンタル - 即時アクセス** をクリックします。

## 5. 時間数を選ぶ

<Steps>

1. 借りたい時間数を入力します。ほとんどの GPU は 1〜168 時間（1 週間）まで借りられます。時間はあとから追加できます。
2. その下の 2 行を確認します。クレジットから確保される金額と、今あるクレジットの額です。
3. レンタルを開始するオレンジ色のボタンをクリックします。ボタンには時間数が表示されます（例: **2 時間のレンタルを開始**）。

</Steps>

<Image src={rent} alt="レンタルページ。時間の入力欄と開始ボタンが強調表示されている" />

<Aside type="tip" title="支払うのは使った分だけ">
開始時に、選んだ時間分の金額がすべて確保されます。レンタルが終わると、実際に使った時間の分だけを秒単位で支払い、残りはクレジットに戻ります。[請求のしくみ](/ja/renters/billing/)をご覧ください。
</Aside>

## 6. API キーをコピーする

**現在のレンタル** のページに移動します。新しいレンタルがいちばん上に表示されます。

<Image src={key} alt="現在のレンタル。API キーの欄、エンドポイントの欄、「時間を追加」「新しいキー」「今すぐ終了」ボタンが強調表示されている" />

1. **API キー。** `gfk_` で始まります。今すぐコピーして、安全な場所に保管してください。**キーが表示されるのは一度だけです。**
2. **エンドポイント:** `https://gpuflow.app/v1`。アプリでは「ベース URL」として使います。
3. **ボタン:** **時間を追加** はレンタルを延長します。**新しいキー** は新しいキーを発行し、古いキーを無効にします。**今すぐ終了** はレンタルを終了し、使わなかった時間分をクレジットに戻します。

キーをなくしたら、**新しいキー** をクリックします。古いキーは使えなくなり、新しいキーが表示されます。

**次へ:** `curl`、Python、JavaScript、またはアプリで [API キーを使う](/ja/renters/api-quickstart/)。

## 借りたい GPU がオフラインの場合

所有者がオフラインの GPU は、黄色の **利用可能 - プロバイダーはオフライン** の欄にあります。カードの **オンラインになったら通知** をクリックします。

<Image src={notify} alt="オフラインの欄にある GPU のカード。「オンラインになったら通知」ボタンが強調表示されている" />

- その GPU がオンラインになると、すぐにメールと通知（ヘッダーのベル）が届きます。
- 所有者には、GPU を待っている人がいることが伝わります。
- 気が変わったら、もう一度ボタンをクリックすると通知を止められます（ボタンの表示は **通知を受け取ります** に変わっています）。
