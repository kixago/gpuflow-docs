## API のエラー

問題が起きると、API はエラーコードを返します。応答の中の `code` を確認してください。

```json
{ "error": { "message": "...", "type": "server_error", "code": "provider_offline" } }
```

| ステータス | `code` | 意味 | 対処法 |
| --- | --- | --- | --- |
| 401 | `invalid_api_key` | キーがない、打ち間違えている、**新しいキー** で置き換えられた、またはレンタルが終了しています。 | キーをもう一度コピーします。ヘッダーが `Authorization: Bearer gfk_…` になっているか確認してください。レンタルが終了していたら、新しく始めます。 |
| 400 | `invalid_body` | 送った内容が正しい JSON になっていません。 | 引用符とカンマを確認してください。[API キーを使う](/ja/renters/api-quickstart/)のサンプルを元にすると確実です。 |
| 503 | `provider_offline` | プロバイダーのマシンが今オフラインです。 | 1 分待ってから、もう一度試してください。10 分間オフラインのままだとレンタルは自動で終了し、支払うのはオフラインになった時点までの分だけです。 |
| 503 | `relay_unreachable` | GPUFlow から、マシンにつながる接続に届きませんでした。 | 少し待ってから、もう一度試してください。何度も起きる場合は、サポートチケットを作成してください。 |
| 502 | `provider_error` | マシンから空の応答が返りました。 | もう一度試してください。何度も起きる場合は、そのレンタルを報告してください。 |
| 503 | `provider_unbound` | キーが GPU に紐付いていません。 | サポートチケットを作成してください。 |

**「model … not found」:** マシンにないモデルを指定しています。[API キーを使う](/ja/renters/api-quickstart/)にある `/v1/models` の確認を実行し、表示された名前を使ってください。

## クレジットの追加

| メッセージ | 解決方法 |
| --- | --- |
| クレジットを追加する前にメールアドレスを確認してください。 | GPUFlow から届いたメールを開き、リンクをクリックします。メールが見つからない場合は、ダッシュボードの黄色いバナーにある **メールを再送信** をクリックし、迷惑メールフォルダーも確認してください。 |
| $10〜$500 の金額を入力してください。 | 1 回に追加できるのは $10〜$500 です。 |
| お支払いはキャンセルされました。請求は発生していません。 | 支払いの前に Stripe のページを離れました。もう一度お試しください。 |
| 支払ったのに、クレジットが表示されない | 1 分待ってから、ページを再読み込みしてください。10 分たっても反映されない場合は、サポートチケットを作成してください。 |

## レンタルの開始

| メッセージ | 解決方法 |
| --- | --- |
| クレジットが足りません: … が必要ですが、残高は … です。 | クレジットを追加するか、借りる時間を減らしてください。 |
| この GPU のマシンは現在オフラインです。 | ほかの GPU を選ぶか、その GPU のカードで **オンラインになったら通知** をクリックしてください。オンラインに戻るとメールが届きます。 |
| …〜… 時間で選んでください。 | GPU ごとに、借りられる時間の最小と最大が決まっています。その範囲の数を選んでください。 |
| これはご自身の出品です。 | 自分の GPU は借りられません。 |
| 試行回数が多すぎます。1 時間後にもう一度お試しください。 | 1 時間待ってください。この制限は、暴走したスクリプトからアカウントを守るためのものです。 |

## それでも解決しない場合

[gpuflow.app/support](https://gpuflow.app/ja/support) でチケットを作成してください。特定のレンタルについての問題なら、そのレンタルの横にある **問題を報告** を使うと、どのレンタルかがこちらでわかります。エラーの `code`、起きた時刻、できれば実行したコマンドやコードも書いてください（**API キーは含めないでください**）。
