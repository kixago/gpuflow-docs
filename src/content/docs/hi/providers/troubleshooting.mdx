## सबसे पहले, एजेंट देखें

इन्हें GPU वाले कंप्यूटर पर चलाएँ:

```bash
systemctl status gpuflow-agent      # should say "active (running)"
journalctl -u gpuflow-agent -n 50   # the last 50 lines of its log
```

ज़्यादातर जवाब इन्हीं 50 लाइनों में होते हैं।

## मेरी मशीन ऑफलाइन दिखती है

1. **क्या कंप्यूटर चालू है और इंटरनेट से जुड़ा है?** एजेंट को पोर्ट 443 (सामान्य HTTPS) पर `gpuflow.app` और `ws.gpuflow.app` तक पहुँचना होता है।
2. **क्या एजेंट चल रहा है?** अगर `systemctl status gpuflow-agent` में `active (running)` नहीं लिखा है, तो उसे शुरू करें:

   ```bash
   sudo systemctl start gpuflow-agent
   ```

3. **अब भी ऑफ़लाइन?** **मेरी मशीनें** खोलें, उस मशीन के कार्ड पर दी गई कमांड कॉपी करें और उसे फिर से चलाएँ। यह एजेंट को फिर से इंस्टॉल करती है और मशीन वही रखती है, इसलिए उसकी लिस्टिंग अपने-आप वापस आ जाती है।

एजेंट के जुड़ने के लगभग एक मिनट के अंदर ऑफ़लाइन रही मशीन ऑनलाइन दिखने लगती है।

## इंस्टॉल की एरर

| आपको दिखता है | क्या करें |
| --- | --- |
| `enrollment failed` और लॉग में लिखा है कि टोकन की अवधि खत्म हो गई | कमांड 15 मिनट तक मान्य रहती है। डैशबोर्ड रीलोड करें, नई कमांड कॉपी करें और उसे चलाएँ। |
| `this installer targets systemd Linux; systemctl not found` | इंस्टॉलर को systemd वाला Linux चाहिए। Windows, macOS और बिना systemd वाले सिस्टम अभी सपोर्ट नहीं होते। |
| `unsupported CPU architecture` | सिर्फ़ 64-bit PC (x86_64) और 64-bit ARM (arm64) सपोर्ट होते हैं। |
| `no enrollment token` | डैशबोर्ड से पूरी कमांड कॉपी करें, `--token` और उसके बाद का सब कुछ मिलाकर। |
| `failed to pull model '…'` | मॉडल का नाम गलत है, या वह आपके GPU में नहीं समाता। कोई छोटा मॉडल आज़माएँ, जैसे `--model qwen2.5:0.5b`। |

## मॉडल धीमा है या लोड नहीं होता

- जो मॉडल आपके GPU की मेमोरी के लिए बहुत बड़ा है, वह धीरे चलता है या बिल्कुल नहीं चलता। कोई छोटा मॉडल चुनें ([AI मॉडल चुनना](/hi/providers/getting-started/#ai-मॉडल-चुनना) देखें)।
- रीस्टार्ट के बाद पहला अनुरोध धीमा होता है, क्योंकि तब मॉडल मेमोरी में लोड हो रहा होता है।
- **मेरी मशीनें** पर GPU का तापमान देखें। ज़्यादा गर्म GPU अपनी रफ़्तार खुद कम कर देता है।

## किराया जल्दी खत्म हो गया

अगर किराये के दौरान आपकी मशीन 10 मिनट तक ऑफ़लाइन रहे, तो किराया खत्म हो जाता है। आपको ऑफ़लाइन होने के पल तक के समय का भुगतान मिलता है, और बाकी राशि किरायेदार को वापस मिलती है। मशीन को जगाए रखें: अपनी सिस्टम सेटिंग में स्लीप और हाइबरनेट बंद कर दें।

## अनइंस्टॉल करें

```bash
sudo systemctl disable --now gpuflow-agent
sudo rm -f /usr/local/bin/gpuflow-agent /etc/systemd/system/gpuflow-agent.service
sudo rm -rf /etc/gpuflow /var/lib/gpuflow /var/lib/private/gpuflow
sudo systemctl daemon-reload
```

Ollama इंस्टॉल ही रहता है। अगर आपको वह नहीं चाहिए, तो उसे अलग से हटाएँ। फिर **मेरी मशीनें** पर कूड़ेदान वाले बटन से मशीन हटा दें।
