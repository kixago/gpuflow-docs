## API एरर

कुछ गलत होने पर API एक एरर कोड के साथ जवाब देता है। जवाब में `code` देखें:

```json
{ "error": { "message": "...", "type": "server_error", "code": "provider_offline" } }
```

| स्टेटस | `code` | इसका मतलब | क्या करें |
| --- | --- | --- | --- |
| 401 | `invalid_api_key` | कुंजी नहीं भेजी गई, गलत लिखी गई, **नई कुंजी** से बदल दी गई, या किराया खत्म हो गया है। | कुंजी फिर से कॉपी करें। जाँचें कि हेडर `Authorization: Bearer gfk_…` है। अगर किराया खत्म हो गया है, तो नया किराया शुरू करें। |
| 400 | `invalid_body` | आपने जो भेजा, वह सही JSON नहीं है। | अपने कोट्स और कॉमा जाँचें। [अपनी API कुंजी इस्तेमाल करें](/hi/renters/api-quickstart/) पेज के उदाहरणों से शुरुआत करना अच्छा रहेगा। |
| 503 | `provider_offline` | प्रदाता की मशीन अभी ऑफ़लाइन है। | एक मिनट रुककर फिर कोशिश करें। अगर वह 10 मिनट तक ऑफ़लाइन रहे, तो किराया अपने-आप खत्म हो जाता है और आप सिर्फ़ ऑफ़लाइन होने तक का भुगतान करते हैं। |
| 503 | `relay_unreachable` | GPUFlow मशीन से जुड़े कनेक्शन तक नहीं पहुँच सका। | थोड़ी देर बाद फिर कोशिश करें। अगर ऐसा बार-बार हो, तो सपोर्ट टिकट खोलें। |
| 502 | `provider_error` | मशीन ने खाली जवाब दिया। | फिर कोशिश करें। अगर ऐसा बार-बार हो, तो किराये की रिपोर्ट करें। |
| 503 | `provider_unbound` | आपकी कुंजी किसी GPU से जुड़ी नहीं है। | सपोर्ट टिकट खोलें। |

**"model … not found":** आपने ऐसा मॉडल माँगा जो मशीन पर नहीं है। [अपनी API कुंजी इस्तेमाल करें](/hi/renters/api-quickstart/) पेज से `/v1/models` वाली जाँच चलाएँ और वही नाम इस्तेमाल करें।

## क्रेडिट जोड़ना

| मैसेज | हल |
| --- | --- |
| क्रेडिट जोड़ने से पहले अपने ईमेल पते की पुष्टि करें। | GPUFlow का ईमेल खोलें और लिंक पर क्लिक करें। ईमेल नहीं आया? अपने डैशबोर्ड पर पीले बैनर में **ईमेल फिर से भेजें** पर क्लिक करें, और अपना स्पैम फ़ोल्डर भी देखें। |
| $10 से $500 के बीच राशि दर्ज करें। | हर टॉप-अप $10 से $500 के बीच होना चाहिए। |
| भुगतान रद्द हुआ। कोई राशि नहीं कटी। | आपने भुगतान करने से पहले Stripe का पेज छोड़ दिया। फिर कोशिश करें। |
| आपने भुगतान कर दिया, लेकिन क्रेडिट अभी तक नहीं दिखे | एक मिनट रुकें और पेज रीलोड करें। 10 मिनट बाद भी कुछ नहीं? सपोर्ट टिकट खोलें। |

## किराया शुरू करना

| मैसेज | हल |
| --- | --- |
| क्रेडिट कम हैं: … चाहिए | क्रेडिट जोड़ें, या कम घंटों के लिए किराये पर लें। |
| इस GPU की मशीन अभी ऑफ़लाइन है। | कोई दूसरा GPU चुनें। या उसके कार्ड पर **ऑनलाइन होने पर सूचित करें** पर क्लिक करें, ताकि उसके वापस आने पर आपको ईमेल मिले। |
| … से … घंटे चुनें। | इस GPU के अपने न्यूनतम और अधिकतम घंटे हैं। इनके बीच की कोई संख्या चुनें। |
| यह आपकी अपनी लिस्टिंग है। | आप अपना ही GPU किराये पर नहीं ले सकते। |
| बहुत अधिक प्रयास। एक घंटे बाद फिर से कोशिश करें। | एक घंटा रुकें। यह सीमा खातों को बेकाबू स्क्रिप्ट से बचाती है। |

## अब भी अटके हैं?

[gpuflow.app/support](https://gpuflow.app/hi/support) पर टिकट खोलें। अगर बात किसी एक किराये की है, तो उसके पास **समस्या की रिपोर्ट करें** इस्तेमाल करें, ताकि हमें पता रहे कि कौन-सा किराया है। एरर का `code`, यह कब हुआ, और हो सके तो आपने जो कमांड या कोड चलाया था, वह भी भेजें (**अपनी API कुंजी के बिना**)।
