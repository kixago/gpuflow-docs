## GPUFlow क्या है

GPUFlow एक मार्केटप्लेस है। यहाँ लोग दूसरे लोगों से घंटे के हिसाब से GPU किराये पर लेते हैं।

- **किरायेदार** कार्ड से क्रेडिट जोड़ते हैं, एक GPU चुनते हैं और उसके लिए एक API कुंजी पाते हैं। यह कुंजी हर उस ऐप या कोड के साथ काम करती है जो OpenAI API इस्तेमाल करता है।
- **प्रदाता** GPU वाले Linux कंप्यूटर पर एक कमांड चलाते हैं, प्रति घंटा कीमत तय करते हैं और पैसे सीधे अपने बैंक खाते में पाते हैं।
