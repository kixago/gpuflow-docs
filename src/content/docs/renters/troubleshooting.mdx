## API errors

When something goes wrong, the API answers with an error code. Look for the `code` in the answer:

```json
{ "error": { "message": "...", "type": "server_error", "code": "provider_offline" } }
```

| Status | `code` | What it means | What to do |
| --- | --- | --- | --- |
| 401 | `invalid_api_key` | The key is missing, mistyped, replaced by **New key**, or the rental has ended. | Copy the key again. Check that the header is `Authorization: Bearer gfk_…`. If the rental ended, start a new one. |
| 400 | `invalid_body` | What you sent isn't valid JSON. | Check your quotes and commas. The examples on [Use your API key](/renters/api-quickstart/) are a good starting point. |
| 503 | `provider_offline` | The provider's machine is offline right now. | Wait a minute and try again. If it stays offline for 10 minutes, the rental ends by itself and you pay only until it went offline. |
| 503 | `relay_unreachable` | GPUFlow couldn't reach the connection to the machine. | Try again in a moment. If it keeps happening, open a support ticket. |
| 502 | `provider_error` | The machine answered with nothing. | Try again. If it keeps happening, report the rental. |
| 503 | `provider_unbound` | Your key isn't attached to a GPU. | Open a support ticket. |

**"model … not found":** you asked for a model the machine doesn't have. Run the `/v1/models` check from [Use your API key](/renters/api-quickstart/) and use that name.

## Adding credits

| Message | Fix |
| --- | --- |
| Confirm your email address before adding credits. | Open the email from GPUFlow and click the link. No email? Click **Resend email** on the yellow banner on your dashboard, and check your spam folder. |
| Enter an amount from $10 to $500. | Each top-up must be between $10 and $500. |
| Payment cancelled. Nothing was charged. | You left the Stripe page before paying. Try again. |
| You paid, but the credits haven't shown up | Wait a minute and reload the page. Still nothing after 10 minutes? Open a support ticket. |

## Starting a rental

| Message | Fix |
| --- | --- |
| Not enough credits: this needs … | Add credits, or rent for fewer hours. |
| This GPU's machine is offline right now. | Pick another GPU, or click **Notify When Online** on its card to get an email when it's back. |
| Choose … to … hours. | This GPU has its own minimum and maximum hours. Pick a number between them. |
| This is your own listing. | You can't rent your own GPU. |
| Too many attempts. Try again in an hour. | Wait an hour. This limit protects accounts from runaway scripts. |

## Still stuck?

Open a ticket at [gpuflow.app/support](https://gpuflow.app/en/support). If it's about one rental, use **Report a problem** next to it so we see which one. Include the error `code`, the time it happened and, if you can, the command or code you ran (**without your API key**).
