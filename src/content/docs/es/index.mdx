## Qué es GPUFlow

GPUFlow es un mercado donde las personas alquilan GPUs a otras personas, por horas.

- **Los inquilinos** añaden créditos con una tarjeta, eligen una GPU y reciben una clave API para usarla. La clave funciona con cualquier app o código que use la API de OpenAI.
- **Los proveedores** ejecutan un comando en una computadora Linux con GPU, fijan un precio por hora y cobran en su cuenta bancaria.
