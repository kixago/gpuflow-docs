## Сначала проверьте агент

Выполните эти команды на компьютере с GPU:

```bash
systemctl status gpuflow-agent      # should say "active (running)"
journalctl -u gpuflow-agent -n 50   # the last 50 lines of its log
```

Чаще всего ответ есть в этих 50 строках.

## Моя машина в статусе «Оффлайн»

1. **Компьютер включён и подключён к интернету?** Агенту нужен доступ к `gpuflow.app` и `ws.gpuflow.app` через порт 443 (обычный HTTPS).
2. **Агент запущен?** Если `systemctl status gpuflow-agent` не показывает `active (running)`, запустите его:

   ```bash
   sudo systemctl start gpuflow-agent
   ```

3. **Всё ещё не в сети?** Откройте **Мои машины**, скопируйте команду с карточки этой машины и выполните её снова. Она переустановит агент и сохранит ту же машину, поэтому её объявление вернётся само.

Машина, которая была не в сети, появляется в статусе «Онлайн» примерно через минуту после подключения агента.

## Ошибки установки

| Что вы видите | Что делать |
| --- | --- |
| `enrollment failed`, а в логе написано, что срок токена истёк | Команда действует 15 минут. Обновите панель управления, скопируйте новую команду и выполните её. |
| `this installer targets systemd Linux; systemctl not found` | Установщику нужен Linux с systemd. Windows, macOS и системы без systemd пока не поддерживаются. |
| `unsupported CPU architecture` | Поддерживаются только 64-битные ПК (x86_64) и 64-битный ARM (arm64). |
| `no enrollment token` | Скопируйте команду из панели управления целиком, включая `--token` и всё, что после него. |
| `failed to pull model '…'` | Название модели указано неверно, или модель не помещается в ваш GPU. Попробуйте модель поменьше, например `--model qwen2.5:0.5b`. |

## Модель работает медленно или не загружается

- Модель, которая слишком велика для памяти вашего GPU, работает медленно или не работает совсем. Выберите модель поменьше (смотрите [выбор модели ИИ](/ru/providers/getting-started/#выбор-модели-ии)).
- Первый запрос после перезапуска обрабатывается дольше, пока модель загружается в память.
- Проверьте температуру GPU на странице **Мои машины**. Перегретый GPU сам снижает скорость.

## Аренда закончилась раньше времени

Если во время аренды ваша машина не в сети 10 минут, аренда завершается. Вы получаете оплату за время до момента отключения, а арендатору возвращается остаток. Не давайте машине засыпать: отключите спящий режим и гибернацию в настройках системы.

## Удаление

```bash
sudo systemctl disable --now gpuflow-agent
sudo rm -f /usr/local/bin/gpuflow-agent /etc/systemd/system/gpuflow-agent.service
sudo rm -rf /etc/gpuflow /var/lib/gpuflow /var/lib/private/gpuflow
sudo systemctl daemon-reload
```

Ollama останется установленной. Если она вам не нужна, удалите её отдельно. Затем удалите машину на странице **Мои машины** кнопкой с корзиной.

<Aside>
Не получилось? Создайте обращение на [gpuflow.app/support](https://gpuflow.app/ru/support) и вставьте последние 50 строк лога (`journalctl -u gpuflow-agent -n 50`).
</Aside>
