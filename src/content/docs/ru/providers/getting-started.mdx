Вы выполняете **одну команду** на компьютере с GPU. Она всё устанавливает, подключает компьютер к GPUFlow и поддерживает это подключение. Docker и SSH не нужны, открывать порты на роутере тоже не нужно.

## Что понадобится

- Компьютер с **64-битным Linux и systemd**. Подойдут Ubuntu, Debian, Fedora, Arch, openSUSE и их производные. Обычные ПК (x86_64) и ARM (arm64) поддерживаются.
- GPU. **Проверено на NVIDIA.** Карты AMD работают через поддержку ROCm в Ollama, но панель управления пока не показывает данные о GPU AMD.
- Право запускать `sudo` на этом компьютере.
- Аккаунт GPUFlow. [Создайте его здесь](https://gpuflow.app/ru/join). Подтвердите и адрес электронной почты: без этого вы не сможете получать выплаты.

<Aside>
Установщика для Windows и macOS пока нет.
</Aside>

## 1. Скопируйте команду установки

<Steps>

1. Откройте **Панель управления** и нажмите **Мои машины** в меню слева.
2. В блоке **Добавьте GPU одной командой** оставьте в поле **Для чего эта машина?** вариант **Новое объявление (настроить, когда машина будет в сети)**.
3. Нажмите **Копировать** рядом с командой.

</Steps>

<Image src={addMachine} alt="Мои машины: выделены поле с командой и кнопка «Копировать»" />

Команда выглядит так (в конце вашей команды будет ваш собственный токен):

```bash
curl -fsSL https://gpuflow.app/downloads/install.sh | sudo bash -s -- --token eyJhbGciOi...
```

<Aside type="caution" title="Используйте её в течение 15 минут">
Токен в команде действует только 15 минут. Если вы видите `enrollment failed`, а в логе написано, что срок токена истёк, обновите панель управления и скопируйте новую команду.
</Aside>

## 2. Выполните её на компьютере с GPU

<Steps>

1. На компьютере с GPU откройте терминал.
2. Вставьте команду и нажмите Enter. Если `sudo` попросит пароль, введите его.
3. Дождитесь этой строки:

   ```
   Enrolled. gpuflow-agent is running.
   ```

   С этого момента компьютер в сети. Затем установщик скачивает модель ИИ. В первый раз это может занять несколько минут.

</Steps>

## 3. Создайте объявление

Вернитесь на страницу **Мои машины**. Ваш компьютер теперь в статусе **Онлайн** с сообщением **Эта машина в сети, но не выставлена.**

<Image src={notListed} alt="Карточка машины, которая в сети, но не выставлена: выделена кнопка «Сдать в аренду»" />

Нажмите **Сдать в аренду**. Откроется форма объявления, в которой эта машина уже выбрана. Укажите название, модель GPU и цену за час, затем нажмите **Выставить GPU**.

Не знаете, что написать и сколько брать? Смотрите [как написать хорошее объявление](/ru/providers/creating-listings/) и [как назначить цену за GPU](/ru/providers/pricing/).

## 4. Проверьте, что объявление работает

Откройте **Мои GPU**. У вашего объявления машина отмечена зелёной точкой. Теперь объявление видно в каталоге, и арендаторы могут его арендовать.

<Image src={myGpus} alt="Мои GPU: объявление с машиной в сети, выделена кнопка «Редактировать»" />

## Другие способы

**Сначала объявление:** нажмите **Выставить GPU**, заполните форму и оставьте в поле **Машина** вариант **Нет, привязать позже**. На странице **Мои GPU** нажмите **Включить** под объявлением. Вы получите команду, которая привяжет компьютер именно к *этому* объявлению, так что потом ничего связывать не придётся.

**Компьютер в статусе «Оффлайн»:** у каждого отключённого компьютера на странице **Мои машины** есть своя команда прямо на карточке. Выполните её на этом компьютере. Она переустановит агент и вернёт **ту же самую машину**, поэтому её объявление снова заработает, а дубликат не появится. Запускать команду из панели управления на одном компьютере повторно всегда безопасно.

## Выбор модели ИИ

Арендаторы пользуются вашим GPU через модели ИИ, которые на нём работают. По умолчанию установщик скачивает `qwen2.5:7b`. Чтобы выбрать другую модель, добавьте `--model` в конец команды:

```bash
curl -fsSL https://gpuflow.app/downloads/install.sh | sudo bash -s -- --token <your token> --model llama3.1:8b
```

Популярные варианты, от маленьких к большим: `qwen2.5:0.5b`, `deepseek-r1:1.5b`, `qwen2.5:7b`, `deepseek-r1:7b`, `llama3.1:8b`, `qwen2.5:14b`. Модель должна помещаться в память GPU (VRAM), поэтому для карт с небольшой памятью выбирайте модель поменьше.

Чтобы позже добавить модель на компьютер, который уже в сети, новый токен не нужен:

```bash
curl -fsSL https://gpuflow.app/downloads/install.sh | sudo bash -s -- --model qwen2.5:14b
```

У вас уже работает свой сервер, совместимый с OpenAI? Добавьте `--engine none --ollama-url http://127.0.0.1:<port>`.

<Aside type="tip">
Укажите модели, которые у вас работают, в описании объявления. Арендаторы ищут их именно там.
</Aside>

## Как проверить работу

```bash
systemctl status gpuflow-agent      # is it running?
journalctl -u gpuflow-agent -f      # live log (Ctrl+C to stop)
```

Агент сам перезапускается после сбоя или перезагрузки. Он устанавливает только **исходящие** соединения, с `gpuflow.app` и `ws.gpuflow.app`, поэтому работает за любым домашним роутером без проброса портов.

## Статистика в реальном времени

На каждой карточке машины на странице **Мои машины** видно (данные обновляются каждые 15 секунд):

- **Скорость (бенчмарк):** токены в секунду для каждой вашей модели, измеренные на вашем компьютере. Агент тестирует модель один раз, когда она появляется, и затем каждый день, но только если машиной никто не пользовался 5 минут. Аренда всегда прерывает тест.
- **Отдано арендаторам:** реальная скорость и время до первого токена в настоящих арендах.
- **GPU:** температура, загрузка, VRAM, потребляемая мощность, вентилятор, частоты, подключение PCIe.
- **Система и модели:** температура и загрузка CPU, ОЗУ, операционная система, аптайм, установленные модели и модель, загруженная прямо сейчас.

Эту статистику видите только вы.

## О чём вам сообщат

Вы получите **письмо и уведомление** (колокольчик вверху сайта), когда:

- **ваш GPU арендовали;**
- **арендатор ждёт** ваш GPU, пока он не в сети (не чаще раза в день для каждого GPU). Включите машину, чтобы получить аренду;
- **вывод отправлен** или не прошёл.

Вы получите **уведомление**, когда аренда закончится (с суммой заработка) и когда доход станет доступен к выводу.
