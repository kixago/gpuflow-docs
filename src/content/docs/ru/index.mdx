## Что такое GPUFlow

GPUFlow — это площадка, где люди арендуют GPU друг у друга с почасовой оплатой.

- **Арендаторы** пополняют кредиты картой, выбирают GPU и получают к нему API-ключ. Ключ работает с любым приложением или кодом, который поддерживает API OpenAI.
- **Провайдеры** запускают одну команду на Linux-компьютере с GPU, назначают цену за час и получают деньги на банковский счёт.
