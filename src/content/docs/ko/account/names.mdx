GPUFlow는 대여할 때 쓰는 이름과 제공자로서 쓰는 이름을 분리하므로, 두 이름이 같은 사람의 것인지 아무도 알 수 없습니다. 이메일 주소와 실명은 절대 표시되지 않습니다. 모든 이름은 **계정 설정 → 내 이름**에서 설정합니다.

## 사용자명

<Tip id="names.username">

사용자명으로 로그인하며(이메일 주소도 가능), 표시 이름을 켜지 않으면 리뷰 옆에 이 이름이 표시됩니다. 길이는 %names.usernameMin%~%names.usernameMax%자이며 a~z 영문자, 숫자, 그리고 그 사이에 하나씩 들어가는 점, 밑줄, 하이픈을 쓸 수 있습니다. 대문자로 써도 다른 이름이 되지 않습니다.

</Tip>

- 사용자명은 계정을 만들 때 정합니다. Google이나 GitHub로 가입하면 다음 단계에서 정합니다.
- 누구나 읽고 입력할 수 있도록 사용자명은 모든 언어에서 라틴 문자를 씁니다.

## 표시 이름

<Tip id="names.display">

표시 이름은 선택 사항입니다. 켜면 리뷰 옆에 사용자명 대신 표시됩니다. 어떤 언어로든 쓸 수 있고 다른 사람과 같아도 됩니다.

</Tip>

## 제공자 이름과 페이지 주소

<Tip id="names.provider">

GPU를 등록하면 대여자에게는 제공자 이름이 보이며 사용자명은 절대 보이지 않습니다. 제공자 페이지 주소는 gpuflow.app/marketplace/provider/ 뒤에 페이지 주소가 붙은 형태입니다. 모든 계정은 'Quiet Falcon' 같은 무작위 제공자 이름으로 시작하며, 언제든 바꿀 수 있습니다.

</Tip>

- 제공자 이름과 페이지 주소는 사용자명이나 대여자로서 쓴 리뷰와 연결되지 않습니다.
- 제공자 페이지에는 등록한 GPU, 제공자 레벨, 대여자들의 리뷰가 표시됩니다.

## 이름 바꾸기

<Tip id="names.changes">

사용자명과 페이지 주소는 %names.changeDays%일에 한 번 바꿀 수 있습니다. 이전 사용자명이나 페이지 주소는 %names.oldNameHoldDays%일 동안 나를 위해 보관되어 다른 사람이 쓸 수 없고, 그동안 이전 페이지 주소로 들어오는 링크도 계속 작동합니다.

</Tip>

## 절대 표시되지 않는 것

- 이메일 주소.
- 실명. 로그인에 쓰는 Google이나 GitHub 계정의 이름도 표시되지 않습니다.
- Google이나 GitHub 프로필 사진. 모든 사람에게 같은 기본 아이콘이 표시됩니다.
- 어떤 대여자 이름과 어떤 제공자 이름이 같은 계정인지.
