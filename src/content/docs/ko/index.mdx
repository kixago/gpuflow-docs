## GPUFlow란

GPUFlow는 다른 사람의 GPU를 시간 단위로 빌려 쓰는 마켓플레이스입니다.

- **대여자**는 카드로 크레딧을 충전하고 GPU를 고른 뒤 그 GPU용 API 키를 받습니다. 이 키는 OpenAI API를 쓰는 앱이나 코드라면 어디서든 작동합니다.
- **제공자**는 GPU가 있는 Linux 컴퓨터에서 명령어 하나를 실행하고 시간당 가격을 정합니다. 수익은 은행 계좌로 받습니다.
