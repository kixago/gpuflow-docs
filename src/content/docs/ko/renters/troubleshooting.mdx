## API 오류

문제가 생기면 API가 오류 코드로 응답합니다. 응답에서 `code`를 찾으세요.

```json
{ "error": { "message": "...", "type": "server_error", "code": "provider_offline" } }
```

| 상태 | `code` | 뜻 | 해결 방법 |
| --- | --- | --- | --- |
| 401 | `invalid_api_key` | 키가 없거나, 잘못 입력되었거나, **새 키**로 교체되었거나, 대여가 끝났습니다. | 키를 다시 복사하세요. 헤더가 `Authorization: Bearer gfk_…`인지 확인하세요. 대여가 끝났다면 새로 시작하세요. |
| 400 | `invalid_body` | 보낸 내용이 올바른 JSON이 아닙니다. | 따옴표와 쉼표를 확인하세요. [API 키 사용하기](/ko/renters/api-quickstart/)의 예제로 시작하면 좋습니다. |
| 503 | `provider_offline` | 제공자의 머신이 지금 오프라인입니다. | 1분 기다렸다가 다시 시도하세요. 10분 동안 계속 오프라인이면 대여가 자동으로 끝나고, 오프라인이 된 시점까지만 냅니다. |
| 503 | `relay_unreachable` | GPUFlow가 머신과의 연결에 닿지 못했습니다. | 잠시 후 다시 시도하세요. 계속 발생하면 지원 티켓을 여세요. |
| 502 | `provider_error` | 머신이 빈 응답을 보냈습니다. | 다시 시도하세요. 계속 발생하면 그 대여를 신고하세요. |
| 503 | `provider_unbound` | 키가 GPU에 연결되어 있지 않습니다. | 지원 티켓을 여세요. |

**"model … not found":** 머신에 없는 모델을 요청했습니다. [API 키 사용하기](/ko/renters/api-quickstart/)에 있는 `/v1/models` 확인을 실행하고 거기 나온 이름을 쓰세요.

## 크레딧 충전

| 메시지 | 해결 방법 |
| --- | --- |
| 크레딧을 충전하기 전에 이메일 주소를 인증해 주세요. | GPUFlow에서 온 메일을 열고 링크를 클릭하세요. 메일이 없나요? 대시보드의 노란 배너에서 **이메일 다시 보내기**를 클릭하고, 스팸 폴더도 확인하세요. |
| $10~$500 사이 금액을 입력해 주세요. | 한 번에 $10부터 $500까지 충전할 수 있습니다. |
| 결제가 취소되었습니다. 청구된 금액은 없습니다. | 결제하기 전에 Stripe 페이지를 벗어났습니다. 다시 시도하세요. |
| 결제했는데 크레딧이 표시되지 않습니다 | 1분 기다렸다가 페이지를 새로고침하세요. 10분이 지나도 그대로라면 지원 티켓을 여세요. |

## 대여 시작

| 메시지 | 해결 방법 |
| --- | --- |
| 크레딧이 부족합니다: …이(가) 필요하지만 … | 크레딧을 충전하거나, 대여 시간을 줄이세요. |
| 이 GPU의 머신이 지금 오프라인입니다. | 다른 GPU를 고르거나, 카드에서 **온라인 시 알림 받기**를 클릭해 다시 온라인이 되면 이메일을 받으세요. |
| …~…시간 중에서 선택해 주세요. | GPU마다 최소·최대 시간이 따로 있습니다. 그 사이의 숫자를 고르세요. |
| 본인이 등록한 상품입니다. | 내 GPU는 내가 대여할 수 없습니다. |
| 시도가 너무 많습니다. 1시간 후에 다시 시도해 주세요. | 1시간 기다리세요. 이 제한은 폭주하는 스크립트로부터 계정을 보호합니다. |

## 그래도 해결되지 않으면

[gpuflow.app/support](https://gpuflow.app/ko/support)에서 티켓을 여세요. 특정 대여에 관한 문제라면 그 대여 옆의 **문제 신고**를 사용하세요. 그래야 어느 대여인지 저희가 알 수 있습니다. 오류 `code`, 발생 시각, 그리고 가능하다면 실행한 명령어나 코드(**API 키는 빼고**)를 함께 적어 주세요.
