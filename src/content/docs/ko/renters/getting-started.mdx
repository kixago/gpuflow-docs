GPUFlow에서 GPU를 대여하는 데는 5분 정도 걸립니다. 이메일 주소와 결제 카드가 필요합니다.

**받는 것:** 정한 시간 동안 GPU 한 대를 쓸 수 있는 API 키입니다. 이 키는 OpenAI 키처럼 작동하므로 OpenAI API를 쓰는 앱이나 스크립트라면 어디서든 사용할 수 있습니다. 따로 로그인할 서버도, 설치할 것도 없습니다.

## 1. 계정 만들기

<Steps>

1. [gpuflow.app](https://gpuflow.app/ko/join)에 접속해 오른쪽 위의 **가입하기**를 클릭합니다.
2. 사용자명, 이메일 주소, 비밀번호(두 번)를 입력합니다.
3. **계정 생성**을 클릭합니다.

</Steps>

<Image src={signup} alt="계정 생성 양식. 사용자명, 이메일, 비밀번호 입력란과 계정 생성 버튼이 강조되어 있습니다" />

비밀번호를 만드는 대신 **Google로 계속하기**나 **GitHub로 계속하기**를 클릭해도 됩니다.

## 2. 이메일 주소 인증하기

GPUFlow가 곧바로 이메일을 보냅니다. 메일을 열고 안에 있는 링크를 클릭하세요.

<Aside type="caution">
이메일 주소를 인증해야 크레딧을 충전할 수 있습니다. 몇 분이 지나도 메일이 오지 않으면 스팸 폴더를 확인하거나, 대시보드 위쪽의 노란 배너에서 **이메일 다시 보내기**를 클릭하세요.
</Aside>

## 3. 크레딧 충전하기

크레딧으로 대여 요금을 냅니다. **1크레딧 = $0.01**이므로 $25를 내면 2,500크레딧을 받습니다.

<Steps>

1. **대시보드**를 열고 왼쪽 메뉴에서 **결제**를 클릭합니다.
2. **크레딧 충전**에서 금액을 클릭하거나 직접 입력합니다. 한 번에 $10부터 $500까지 충전할 수 있습니다. 수수료는 없습니다.
3. **결제로 이동**을 클릭합니다. 결제 파트너인 Stripe로 이동해 카드로 결제합니다.
4. 결제가 끝나면 GPUFlow로 돌아옵니다. 크레딧은 1분 안에 결제 페이지 위쪽과 헤더의 주황색 버튼에 표시됩니다.

</Steps>

<Image src={credits} alt="결제 페이지. 금액 버튼과 결제로 이동 버튼이 강조되어 있습니다" />

## 4. GPU 고르기

아무 페이지에서나 위쪽의 **GPU 찾아보기**를 클릭합니다. 지금 바로 쓸 수 있는 GPU는 초록색 **즉시 액세스 가능** 섹션에 있습니다.

<Image src={market} alt="마켓플레이스. GPU 카드 하나와 그 카드의 지금 대여하기 버튼이 강조되어 있습니다" />

카드마다 다음을 확인하세요.

- **시간당 가격.** 1시간을 쓰는 데 드는 비용입니다.
- **VRAM.** 큰 AI 모델일수록 더 많이 필요합니다. 대략 7B 모델은 8GB 이상, 14B 모델은 16GB 이상이면 잘 돌아갑니다.
- **모델.** GPU 이름을 클릭하면 상세 페이지가 열립니다. 제공자는 어떤 AI 모델을 제공하는지(예: `qwen2.5:7b`) 설명에 적어 둡니다.

마음에 드는 GPU를 골랐다면 **지금 대여하기 - 즉시 액세스**를 클릭합니다.

## 5. 대여 시간 정하기

<Steps>

1. 원하는 시간을 입력합니다. 대부분의 GPU는 1시간부터 168시간(1주일)까지 가능합니다. 시간은 나중에 더 추가할 수 있습니다.
2. 그 아래 두 줄을 확인합니다. 크레딧에서 얼마가 확보되는지, 그리고 지금 크레딧이 얼마 있는지가 나옵니다.
3. 대여를 시작하는 주황색 버튼을 클릭합니다. 버튼에는 입력한 시간이 표시됩니다. 예: **2시간 대여 시작**.

</Steps>

<Image src={rent} alt="대여 페이지. 시간 입력란과 시작 버튼이 강조되어 있습니다" />

<Aside type="tip" title="쓴 만큼만 냅니다">
시작할 때 선택한 시간의 전체 금액이 확보됩니다. 대여가 끝나면 실제로 쓴 시간만 초 단위로 결제되고, 나머지는 크레딧으로 돌아옵니다. [결제 방식 알아보기](/ko/renters/billing/).
</Aside>

## 6. API 키 복사하기

**현재 대여** 페이지로 이동합니다. 새 대여가 맨 위에 있습니다.

<Image src={key} alt="현재 대여. API 키 칸, 엔드포인트 칸, 시간 추가·새 키·지금 종료 버튼이 강조되어 있습니다" />

1. **API 키.** `gfk_`로 시작합니다. 지금 복사해서 안전한 곳에 보관하세요. **키는 한 번만 표시됩니다.**
2. **엔드포인트:** `https://gpuflow.app/v1`. 앱에서 "base URL"(기본 URL)로 사용합니다.
3. **버튼:** **시간 추가**는 대여 시간을 늘립니다. **새 키**는 새 키를 만들고 이전 키를 끕니다. **지금 종료**는 대여를 멈추고 쓰지 않은 시간을 크레딧으로 돌려줍니다.

키를 잃어버렸나요? **새 키**를 클릭하세요. 이전 키는 작동을 멈추고 새 키가 나타납니다.

**다음:** `curl`, Python, JavaScript 또는 앱에서 [API 키 사용하기](/ko/renters/api-quickstart/).

## 원하는 GPU가 오프라인일 때

주인이 오프라인인 GPU는 노란색 **사용 가능 - 제공자 오프라인** 섹션에 있습니다. 카드에서 **온라인 시 알림 받기**를 클릭하세요.

<Image src={notify} alt="오프라인 섹션의 GPU 카드. 온라인 시 알림 받기 버튼이 강조되어 있습니다" />

- 그 GPU가 온라인이 되면 바로 이메일과 알림(헤더의 종 모양 아이콘)을 받습니다.
- GPU 주인에게는 누군가 기다리고 있다는 알림이 갑니다.
- 마음이 바뀌었나요? 버튼을 다시 클릭하면(이때 버튼에는 **알림을 받게 됩니다**라고 표시됩니다) 알림이 해제됩니다.

## 대여 평가하기

대여가 끝나면 평가를 남길 수 있습니다. 평가는 다른 대여자가 GPU를 고를 때 도움이 되고, 좋은 제공자가 대여를 더 받는 데도 도움이 됩니다.

<Steps>

1. **대시보드 → 대여 내역**을 엽니다.
2. 해당 대여를 찾아 **이 대여 평가하기**를 클릭합니다.
3. 별을 1~5개 클릭합니다. 코멘트는 선택 사항입니다.
4. **리뷰 게시**를 클릭합니다.

</Steps>

<Image src={rate} alt="평가 창. 별, 코멘트 입력란, 리뷰 게시 버튼이 강조되어 있습니다" />

GPU를 어디에 썼고 어땠는지 적으면 도움이 되는 코멘트가 됩니다. 예:

> qwen2.5:7b로 두 시간 정도 썼어요. 응답이 빠르고 끊김도 없었어요. 설명에 적힌 모델도 다 있었고요.

알아 두면 좋은 점:

- 비용을 낸 대여라면 끝난 뒤 30일 동안 평가할 수 있습니다.
- 리뷰는 게시 후 14일 동안 수정할 수 있습니다. **대여 내역**에서 **리뷰 수정**을 클릭하세요.
- 리뷰에는 GPUFlow 사용자명이 함께 표시됩니다. 이메일 주소는 표시되지 않습니다.
- 제공자는 내 리뷰 아래에 공개 답글을 달 수 있습니다. 답글이 달리면 알림을 받습니다.
