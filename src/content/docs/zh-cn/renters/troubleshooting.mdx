## API 错误

出错时，API 会返回一个错误代码。请查看回复中的 `code`：

```json
{ "error": { "message": "...", "type": "server_error", "code": "provider_offline" } }
```

| 状态码 | `code` | 含义 | 处理方法 |
| --- | --- | --- | --- |
| 401 | `invalid_api_key` | 缺少密钥、密钥输错、已被 **新密钥** 替换，或租用已结束。 | 重新复制密钥。检查请求头是否为 `Authorization: Bearer gfk_…`。如果租用已结束，请开始一个新的租用。 |
| 400 | `invalid_body` | 您发送的内容不是有效的 JSON。 | 检查引号和逗号。[使用您的 API 密钥](/zh-cn/renters/api-quickstart/)中的示例是不错的起点。 |
| 503 | `provider_offline` | 提供者的机器目前离线。 | 等一分钟再试。如果离线持续 10 分钟，租用会自动结束，您只需支付到离线时为止的费用。 |
| 503 | `relay_unreachable` | GPUFlow 无法连上与这台机器之间的连接通道。 | 稍后再试。如果反复出现，请提交客服工单。 |
| 502 | `provider_error` | 机器返回了空回复。 | 再试一次。如果反复出现，请报告这次租用。 |
| 503 | `provider_unbound` | 您的密钥没有关联到任何 GPU。 | 请提交客服工单。 |

**“model … not found”**：您请求的模型在这台机器上不存在。运行[使用您的 API 密钥](/zh-cn/renters/api-quickstart/)中的 `/v1/models` 检查，并使用查到的名称。

## 充值额度

| 提示信息 | 解决办法 |
| --- | --- |
| 充值前请先验证您的电子邮件地址。 | 打开 GPUFlow 发来的邮件，点击其中的链接。没收到邮件？点击仪表板上黄色横幅中的 **重新发送邮件**，并查看垃圾邮件文件夹。 |
| 请输入 $10 至 $500 之间的金额。 | 每次充值金额必须在 $10 到 $500 之间。 |
| 付款已取消，未产生任何扣费。 | 您在付款前离开了 Stripe 页面。请再试一次。 |
| 您已付款，但额度还没有到账 | 等一分钟后刷新页面。10 分钟后仍然没有？请提交客服工单。 |

## 开始租用

| 提示信息 | 解决办法 |
| --- | --- |
| 额度不足：需要 … | 充值额度，或减少租用小时数。 |
| 此 GPU 的机器目前离线。 | 换一块 GPU，或点击它卡片上的 **上线时通知我**，它重新上线时您会收到邮件。 |
| 请选择 … 至 … 小时。 | 这块 GPU 有自己的最短和最长时长。请选一个在此范围内的数字。 |
| 这是您自己的上架信息。 | 您不能租用自己的 GPU。 |
| 尝试次数过多。请一小时后重试。 | 等一小时。这个限制可以防止失控的脚本影响账户。 |

## 仍然无法解决？

在 [gpuflow.app/support](https://gpuflow.app/zh-CN/support) 提交工单。如果问题与某次租用有关，请使用该租用旁边的 **报告问题**，这样我们就知道是哪一次。请附上错误 `code`、发生的时间，如果可以，再附上您运行的命令或代码（**不要包含您的 API 密钥**）。
