租用者选您的 GPU 还是别人的，最主要看价格。下面说明您能拿到多少、运行成本是多少，以及和您类似的 GPU 目前的租金。

## 您能拿到多少

您设定每小时价格。租用者按使用时间支付这个价格。**GPUFlow 收取 12%，您得到 88%**。

| 您的每小时价格 | 您每小时的收益 | 每天 8 小时，持续 30 天 |
| --- | --- | --- |
| $0.10 | $0.088 | $21.12 |
| $0.20 | $0.176 | $42.24 |
| $0.35 | $0.308 | $73.92 |
| $0.50 | $0.44 | $105.60 |

最后一列假设您的 GPU 每天被租用 8 小时。实际使用情况取决于您的价格、您选择的模型，以及您在线的频率。

## 运行成本是多少

主要成本是电费。您一分钟就能算出来：

<Steps>

1. 在 GPU 忙碌时打开 **我的机器**。卡片上会以瓦为单位显示它的**功耗**。
2. 除以 1,000，换算成千瓦。350 W 就是 0.35 kW。
3. 乘以您每千瓦时的电价（电费账单上有）。

</Steps>

例如：0.35 kW × 每千瓦时 $0.15 = **每小时 $0.053**。您每小时的收益应该明显高于这个数。

<Aside type="note" title="为什么先定在区间的下半部分">
在上述大多数网站上，租用者得到的是整台机器。在 GPUFlow 上，他们通过 API 使用您的 AI 模型。这对他们来说更简单，但能做的事更少，所以请把价格定在区间的下半部分，至少在您拿到最初几次租用之前。
</Aside>

## 上架表单中的价格条

在 **上架 GPU** 或 **编辑** 中输入小时费率时，字段下方会出现一个价格条，显示您的价格处在什么位置：

<Image src={bar} alt="小时费率字段下方的价格条，显示该价格对这款 GPU 来说属于常见价格" />

- **绿色区间，“其他租赁网站”**：您这款 GPU 在其他租赁网站上的常见价格范围，数据来自上表。
- **蓝色线，“GPUFlow 上该型号的其他上架”**：GPUFlow 上同一 GPU 型号的其他上架信息的平均价格，以及它们的最低价和最高价。只有存在这类上架信息时才会显示。
- **橙色标记**：您的价格。价格条下方的一行会显示 **价格偏低**、**常见价格** 或 **价格偏高**，最后一行告诉您扣除 12% 费用后每小时能赚多少。

如果您的 GPU 不在上表中，GPUFlow 上也还没有人上架同款，价格条就无法比较。请以表中最接近的显卡作为参考。

## 定价：一个简单的方法

<Steps>

1. **从低价开始**。在您这款 GPU 的价格区间中，选下三分之一的价格。RTX 4090 大约是 $0.30 – $0.35。
2. **保持在线**。租用者无法租用离线的 GPU。在线时长比几美分的差价更重要。
3. **一周后再看一次**。
   - 大部分时间都有人租？把价格提高 $0.02 – $0.05。
   - 完全没人租？把价格降低 $0.02 – $0.05，并检查描述中是否写明了您的模型。
4. **每月检查一次**。其他网站的价格会变动。在 **我的 GPU → 编辑** 中修改您的价格。

</Steps>
