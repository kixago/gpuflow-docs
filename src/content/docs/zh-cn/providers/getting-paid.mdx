## 钱如何到您手里

<Steps>

1. **租用结束**。租用者为使用的时间付费。GPUFlow 收取 12%，其余 88% 归您。
2. **您的收益会暂扣 7 天**。它们显示在 **仪表板 → 支付** 的 **暂扣收益** 下。如果您的账户注册不满 30 天，暂扣期为 14 天。暂扣是为了防范银行卡欺诈和付款争议。
3. **收益变为可提现**。暂扣期结束后，收益会转入 **可提现**，您会收到一条通知。
4. **您提现**，通过我们的支付合作伙伴 Stripe 转到您的银行账户。

</Steps>

您也可以用收益去租用其他 GPU。用银行卡购买的额度可以消费，但不能提现。

## 设置收款（只需一次）

您需要一个已验证的电子邮件地址，以及一个 Stripe 收款账户。Stripe 会核验您的身份，并询问您的银行信息。整个过程只需几分钟。

<Steps>

1. 打开 **仪表板 → 支付**。
2. 在 **提现** 下，选择您居住或企业注册所在的国家/地区。
3. 点击 **通过 Stripe 设置提现**，按照 Stripe 的步骤操作。请准备好身份证件和银行信息。
4. 完成后，Stripe 会把您送回 GPUFlow。

</Steps>

<Image src={setup} alt="提现框：国家/地区列表和“通过 Stripe 设置提现”按钮已高亮" />

Stripe 有时会先审核您的资料。通常需要几分钟，有时需要一两天。如果还有步骤没完成，您会看到 **在 Stripe 继续设置**。

**支持提现的国家和地区**：美国、加拿大、英国、瑞士，以及欧洲经济区：奥地利、比利时、保加利亚、克罗地亚、塞浦路斯、捷克、丹麦、爱沙尼亚、芬兰、法国、德国、希腊、匈牙利、冰岛、爱尔兰、意大利、拉脱维亚、列支敦士登、立陶宛、卢森堡、马耳他、荷兰、挪威、波兰、葡萄牙、罗马尼亚、斯洛伐克、斯洛文尼亚、西班牙和瑞典。

## 提现

<Steps>

1. 打开 **仪表板 → 支付**。
2. 在 **提现** 下，输入金额，或保留已填好的全部金额。
3. 看一下下方那一行：它显示 $2.50 的手续费，以及您实际收到的金额。
4. 点击 **提现**。

</Steps>

<Image src={cashout} alt="提现框，金额字段和“提现”按钮已高亮" />

- **最低金额**：每次提现 $25。
- **手续费**：每次提现 $2.50，与金额无关。减少提现次数可以省下手续费。
- 钱以美元发送到您的 Stripe 收款账户，再由 Stripe 转到您的银行账户。
- 发出后，您会收到一封邮件和一条通知。如果提现未成功，全部金额会退回您的余额。
- 您可以随时通过 **在 Stripe 管理收款信息** 更改银行信息。

## 如果租用者对银行卡付款提出争议

有时租用者会要求银行撤销一笔银行卡付款。发生这种情况时，GPUFlow 会收回该租用者的租用中**仍在暂扣期内**的收益，您会收到一封相关邮件。如果争议的结果对我们有利，这些收益会退还给您。已经过了暂扣期的收益不受影响。

<Aside type="note">
您的收益属于收入。如何纳税取决于您所在的地方。如果不确定，请咨询税务顾问。
</Aside>
