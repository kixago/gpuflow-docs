## GPUFlow 是什么

GPUFlow 是一个交易平台，用户可以按小时向其他人租用 GPU。

- **租用者**用银行卡充值额度，选一块 GPU，然后获得它的 API 密钥。任何支持 OpenAI API 的应用或代码都能使用这个密钥。
- **提供者**在一台装有 GPU 的 Linux 电脑上运行一条命令，设定每小时价格，收益会打到自己的银行账户。
