GPUFlow 会把您租用时使用的名称和您作为提供者使用的名称分开，所以没人能看出两者属于同一个人。您的电子邮件地址和真实姓名永远不会显示。所有名称都在 **账户设置 → 你的名称** 中设置。

## 用户名

<Tip id="names.username">

您用用户名登录（也可以用电子邮件地址），在您开启显示名称之前，它也是显示在您评论旁边的名称。长度为 %names.usernameMin% 到 %names.usernameMax% 个字符：英文字母 a 到 z、数字，以及夹在它们之间的单个点、下划线或连字符。大小写不同不算不同的名称。

</Tip>

- 您在创建账户时选择用户名。如果用 Google 或 GitHub 注册，会在下一步选择。
- 所有语言的用户名都使用拉丁字母，方便每个人阅读和输入。

## 显示名称

<Tip id="names.display">

显示名称是可选的。开启后，您评论旁边显示的是它，而不是用户名。它可以用任何语言，也不必唯一。

</Tip>

## 提供者名称和页面地址

<Tip id="names.provider">

您上架 GPU 后，租用者看到的是您的提供者名称，永远看不到用户名。您的提供者页面位于 gpuflow.app/marketplace/provider/ 后接您的页面地址。每个账户一开始都有一个随机的提供者名称，例如“Quiet Falcon”，您可以随时更改。

</Tip>

- 您的提供者名称和页面地址与您的用户名、以及您作为租用者写的评论都没有关联。
- 您的提供者页面会显示您的上架信息、提供者等级和租用者的评论。

## 更改名称

<Tip id="names.changes">

用户名和页面地址每 %names.changeDays% 天可以更改一次。旧的用户名或页面地址会为您保留 %names.oldNameHoldDays% 天，其他人不能使用，在此期间指向旧页面地址的链接也仍然有效。

</Tip>

## 永远不会显示的内容

- 您的电子邮件地址。
- 您的真实姓名，包括您用来登录的 Google 或 GitHub 账户上的姓名。
- 您在 Google 或 GitHub 上的头像。所有人显示的都是同一个简单图标。
- 哪个租用者名称和哪个提供者名称属于同一个账户。
