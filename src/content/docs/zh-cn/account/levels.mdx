您有两个等级，一个用于租用，一个用于提供，各自有自己的积分。租用者会在您的上架信息和提供者页面上看到您的提供者等级。您的租用者等级显示在您的评论旁边，您租用的提供者也能看到。两个等级永远不会同时显示。您的仪表板会在 **你的等级** 中显示两者以及最近的积分。

## 积分如何运作

<Tip id="levels.points">

积分来自已完成的付费租用和评价。租用者和提供者每付费一小时都会获得积分，每次租用最多 %points.maxPerRental% 分，评价也会增加或减少积分。每次变动都有记录，所以您的总分随时可以逐条说明。

</Tip>

| 发生的事 | 租用者 | 提供者 |
| --- | --- | --- |
| 一次付费租用结束 | 每付费一小时 +%points.perPaidHour%，最多 %points.maxPerRental% | 每付费一小时 +%points.perPaidHour%，最多 %points.maxPerRental% |
| 您评价了对方 | %points.ratingGiven% | %points.ratingGiven% |
| 收到评论：5 / 4 / 3 / 2 / 1 星 | — | %points.stars5% / %points.stars4% / %points.stars3% / %points.stars2% / %points.stars1% |
| 提供者愿意 / 不愿意再次租给您 | %points.thumbsUp% / %points.thumbsDown% | — |
| 整个租用期间机器保持在线 | — | %points.onlineWholeRental% |
| 租用期间机器离线 | — | %points.machineOffline% |
| 您的一笔银行卡付款被争议 | %points.cardDispute% | — |
| 您的评论因滥用被工作人员移除 | %points.reviewHidden% | — |

### 不计积分的情况

- 付费时长不足 %points.minPaidMinutes% 分钟的租用。
- 同一租用者和提供者之间每月超过 %points.pairMonthlyCap% 次的租用。只有前 %points.pairMonthlyCap% 次计分。
- 正在核查的租用（见下文）。

## 等级

<Tip id="levels.levels">

共有 %levels.max% 个等级。积分一达到下一个等级就会升级。即使一段时间不使用，等级也不会下降。只有积分低于您下一级的门槛时才会降级，所以一次糟糕的租用不会让等级反复升降。

</Tip>

| 等级 | 所需积分 |
| --- | --- |
| 1 | %levels.thresholds.0% |
| 2 | %levels.thresholds.1% |
| 3 | %levels.thresholds.2% |
| 4 | %levels.thresholds.3% |
| 5 | %levels.thresholds.4% |
| 6 | %levels.thresholds.5% |
| 7 | %levels.thresholds.6% |
| 8 | %levels.thresholds.7% |
| 9 | %levels.thresholds.8% |
| 10 | %levels.thresholds.9% |

## 等级解锁的权益

<Tip id="levels.perks">

等级 %levels.searchLevel% 及以上的提供者，在价格或评分相同时会排在其他提供者前面；等级 %earnings.shortHoldLevel% 及以上、且账户注册满 %earnings.shortHoldMinAgeDays% 天的提供者，收益在 %earnings.shortHoldDays% 天后即可使用，而不是 %earnings.holdDays% 天。开启两步验证的租用者，从等级 %credits.topupLevel1% 起单次最多可充值 %credits.topupLevel1Usd%，从等级 %credits.topupLevel2% 起最多 %credits.topupLevel2Usd%。

</Tip>

仪表板上的 **你的等级** 会列出下一个等级解锁的内容。以后可能会增加更多权益。

## 新账户

<Tip id="levels.newAccounts">

一次租用的积分要等两个账户都注册满 %points.newAccountDays% 天后才计入。在此之前，它们会在 **你的等级** 中显示为暂扣，并附上计入日期。

</Tip>

## 核查期间暂扣的积分

<Tip id="levels.review">

有时 GPUFlow 会更仔细地核查一次租用，例如两个账户看起来有关联，或某笔付款看起来不寻常。核查期间，这次租用的积分不计入，两个账户都无法升级。大多数核查会自动结束，核查通过后积分就会加上。

</Tip>

租用本身不受影响。如果您认为核查有误，请[提交支持工单](https://gpuflow.app/zh-CN/support)。
