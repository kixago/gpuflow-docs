## ما هي GPUFlow

GPUFlow سوق يستأجر فيه الناس وحدات GPU من أشخاص آخرين، بالساعة.

- **المستأجرون** يشحنون رصيدهم بالبطاقة، ويختارون وحدة GPU، ويحصلون على مفتاح API لها. يعمل المفتاح مع أي تطبيق أو كود يتعامل مع OpenAI API.
- **المزودون** ينفّذون أمراً واحداً على كمبيوتر يعمل بنظام Linux وفيه وحدة GPU، ويحددون سعراً بالساعة، ويتلقون أرباحهم في حسابهم المصرفي.
