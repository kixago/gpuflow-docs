## أولاً، افحص الوكيل

نفّذ هذه الأوامر على كمبيوتر وحدة GPU:

```bash
systemctl status gpuflow-agent      # يجب أن يظهر "active (running)"
journalctl -u gpuflow-agent -n 50   # آخر 50 سطراً من السجل
```

معظم الإجابات موجودة في هذه الأسطر الخمسين.

## جهازي يظهر غير متصل

1. **هل الكمبيوتر يعمل ومتصل بالإنترنت؟** يحتاج الوكيل إلى الوصول إلى `gpuflow.app` و`ws.gpuflow.app` على المنفذ 443 (اتصال HTTPS عادي).
2. **هل الوكيل يعمل؟** إذا لم يُظهر `systemctl status gpuflow-agent` العبارة `active (running)`، فشغّله:

   ```bash
   sudo systemctl start gpuflow-agent
   ```

3. **ما زال غير متصل؟** افتح **أجهزتي**، وانسخ الأمر الموجود على بطاقة ذلك الجهاز ونفّذه مرة أخرى. يعيد الأمر تثبيت الوكيل ويحتفظ بالجهاز نفسه، فيعود إعلانه تلقائياً.

الجهاز الذي كان غير متصل يظهر متصلاً خلال دقيقة تقريباً من اتصال الوكيل.

## أخطاء التثبيت

| ما تراه | ما العمل |
| --- | --- |
| `enrollment failed` ويذكر السجل أن صلاحية الرمز انتهت | الأمر صالح لمدة 15 دقيقة. أعد تحميل لوحة التحكم، وانسخ أمراً جديداً ونفّذه. |
| `this installer targets systemd Linux; systemctl not found` | يحتاج برنامج التثبيت إلى Linux مع systemd. أنظمة Windows وmacOS والأنظمة التي لا تستخدم systemd غير مدعومة بعد. |
| `unsupported CPU architecture` | الأجهزة المدعومة هي فقط أجهزة الكمبيوتر العادية بإصدار 64-bit (x86_64) وأجهزة ARM بإصدار 64-bit (arm64). |
| `no enrollment token` | انسخ الأمر كاملاً من لوحة التحكم، بما في ذلك `--token` وكل ما بعده. |
| `failed to pull model '…'` | اسم النموذج خاطئ، أو النموذج لا يتسع في وحدة GPU لديك. جرّب نموذجاً أصغر، مثل `--model qwen2.5:0.5b`. |

## النموذج بطيء أو لا يُحمَّل

- النموذج الأكبر من ذاكرة وحدة GPU يعمل ببطء أو لا يعمل إطلاقاً. اختر نموذجاً أصغر (راجع [اختيار نموذج الذكاء الاصطناعي](/ar/providers/getting-started/#اختيار-نموذج-الذكاء-الاصطناعي)).
- أول طلب بعد إعادة التشغيل أبطأ، لأن النموذج يُحمَّل في الذاكرة.
- تحقق من حرارة وحدة GPU في **أجهزتي**. وحدة GPU الساخنة تخفّض سرعتها بنفسها.

## انتهى استئجار مبكراً

إذا بقي جهازك غير متصل لمدة 10 دقائق أثناء استئجار، ينتهي الاستئجار. تحصل على أجرك عن الوقت حتى لحظة انقطاع الاتصال، ويستعيد المستأجر الباقي. أبقِ الجهاز مستيقظاً: أوقف وضعَي السكون والإسبات في إعدادات النظام.

## إزالة التثبيت

```bash
sudo systemctl disable --now gpuflow-agent
sudo rm -f /usr/local/bin/gpuflow-agent /etc/systemd/system/gpuflow-agent.service
sudo rm -rf /etc/gpuflow /var/lib/gpuflow /var/lib/private/gpuflow
sudo systemctl daemon-reload
```

يبقى Ollama مثبتاً. أزِله بشكل منفصل إذا لم تكن تريده. بعد ذلك احذف الجهاز من **أجهزتي** بزر سلة المهملات.

<Aside>
ما زلت عالقاً؟ افتح تذكرة على [gpuflow.app/support](https://gpuflow.app/ar/support) والصق آخر 50 سطراً من السجل (`journalctl -u gpuflow-agent -n 50`).
</Aside>
