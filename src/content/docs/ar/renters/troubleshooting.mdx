## أخطاء API

عندما يحدث خطأ، يرد API برمز خطأ. ابحث عن `code` في الرد:

```json
{ "error": { "message": "...", "type": "server_error", "code": "provider_offline" } }
```

| الحالة | `code` | معناه | ما العمل |
| --- | --- | --- | --- |
| 401 | `invalid_api_key` | المفتاح غير موجود، أو فيه خطأ في الكتابة، أو استُبدل بـ **مفتاح جديد**، أو انتهى الاستئجار. | انسخ المفتاح مرة أخرى. تحقق من أن الترويسة هي `Authorization: Bearer gfk_…`. إذا انتهى الاستئجار، فابدأ استئجاراً جديداً. |
| 400 | `invalid_body` | ما أرسلته ليس JSON صالحاً. | تحقق من علامات الاقتباس والفواصل. الأمثلة في [استخدام مفتاح API](/ar/renters/api-quickstart/) نقطة بداية جيدة. |
| 503 | `provider_offline` | جهاز المزوّد غير متصل الآن. | انتظر دقيقة وحاول مرة أخرى. إذا بقي غير متصل 10 دقائق، ينتهي الاستئجار تلقائياً وتدفع فقط حتى لحظة انقطاعه. |
| 503 | `relay_unreachable` | لم تتمكن GPUFlow من الوصول إلى الاتصال بالجهاز. | حاول مرة أخرى بعد قليل. إذا تكرر ذلك، فافتح تذكرة دعم. |
| 502 | `provider_error` | رد الجهاز دون أي محتوى. | حاول مرة أخرى. إذا تكرر ذلك، فأبلغ عن الاستئجار. |
| 503 | `provider_unbound` | مفتاحك غير مرتبط بوحدة GPU. | افتح تذكرة دعم. |

**"model … not found":** طلبت نموذجاً غير موجود على الجهاز. نفّذ فحص `/v1/models` الموجود في [استخدام مفتاح API](/ar/renters/api-quickstart/) واستخدم الاسم الذي يظهر.

## شحن الرصيد

| الرسالة | الحل |
| --- | --- |
| أكّد بريدك الإلكتروني قبل شحن الرصيد. | افتح رسالة GPUFlow وانقر على الرابط. لم تصلك رسالة؟ انقر على **إعادة إرسال البريد** في الشريط الأصفر في لوحة التحكم، وتحقق من مجلد الرسائل غير المرغوب فيها. |
| أدخل مبلغاً من $10 إلى $500. | يجب أن تكون كل عملية شحن بين $10 و$500. |
| أُلغي الدفع. لم يُخصم أي مبلغ. | غادرت صفحة Stripe قبل الدفع. حاول مرة أخرى. |
| دفعت، لكن الرصيد لم يظهر | انتظر دقيقة ثم أعد تحميل الصفحة. لم يظهر شيء بعد 10 دقائق؟ افتح تذكرة دعم. |

## بدء الاستئجار

| الرسالة | الحل |
| --- | --- |
| الرصيد غير كافٍ: المطلوب … | اشحن رصيدك، أو استأجر لعدد أقل من الساعات. |
| جهاز وحدة GPU هذه غير متصل حالياً. | اختر وحدة GPU أخرى، أو انقر على **إعلامي عند الاتصال** في بطاقتها ليصلك بريد إلكتروني عند عودتها. |
| اختر من … إلى … ساعة. | لهذه الوحدة حد أدنى وحد أقصى خاصان بها من الساعات. اختر عدداً بينهما. |
| هذا إعلانك أنت. | لا يمكنك استئجار وحدة GPU الخاصة بك. |
| محاولات كثيرة جداً. حاول مرة أخرى بعد ساعة. | انتظر ساعة. يحمي هذا الحد الحسابات من السكربتات التي تخرج عن السيطرة. |

## ما زلت عالقاً؟

افتح تذكرة على [gpuflow.app/support](https://gpuflow.app/ar/support). إذا كان الأمر يتعلق باستئجار واحد، فاستخدم **الإبلاغ عن مشكلة** بجانبه حتى نعرف أي استئجار تقصد. اذكر `code` الخطأ، ووقت حدوثه، وإن أمكن الأمر أو الكود الذي نفّذته (**بدون مفتاح API الخاص بك**).
