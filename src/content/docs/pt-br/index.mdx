## O que é o GPUFlow

O GPUFlow é um marketplace onde pessoas alugam GPUs de outras pessoas, por hora.

- **Locatários** adicionam créditos com cartão, escolhem uma GPU e recebem uma chave de API para ela. A chave funciona com qualquer app ou código que use a API da OpenAI.
- **Provedores** executam um comando em um computador Linux com GPU, definem um preço por hora e recebem o pagamento na conta bancária.
