## What GPUFlow is

GPUFlow is a marketplace where people rent GPUs from other people, by the hour.

- **Renters** add credits with a card, pick a GPU and get an API key for it. The key works with any app or code that speaks the OpenAI API.
- **Providers** run one command on a Linux computer with a GPU, set an hourly price, and get paid to their bank account.
