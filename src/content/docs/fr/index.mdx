## Ce qu'est GPUFlow

GPUFlow est une place de marché où des particuliers louent des GPU à d'autres particuliers, à l'heure.

- Les **locataires** ajoutent des crédits par carte, choisissent un GPU et reçoivent une clé API pour ce GPU. La clé fonctionne avec toute application ou tout code compatible avec l'API OpenAI.
- Les **fournisseurs** lancent une commande sur un ordinateur Linux équipé d'un GPU, fixent un prix à l'heure et sont payés sur leur compte bancaire.
