GPUFlow sépare le nom que vous utilisez pour louer de celui que vous utilisez comme fournisseur, pour que personne ne puisse savoir qu'ils appartiennent à la même personne. Votre adresse e-mail et votre vrai nom ne sont jamais affichés. Vous réglez tous vos noms dans **Paramètres du compte → Vos noms**.

## Nom d'utilisateur

<Tip id="names.username">

Votre nom d'utilisateur sert à vous connecter (votre adresse e-mail fonctionne aussi), et c'est le nom affiché à côté de vos avis, sauf si vous activez un nom affiché. Il fait de %names.usernameMin% à %names.usernameMax% caractères : lettres de a à z, chiffres et, entre eux, des points, tirets bas ou tirets isolés. Les majuscules ne font pas un autre nom.

</Tip>

- Vous le choisissez en créant votre compte. Si vous vous inscrivez avec Google ou GitHub, vous le choisissez à l'étape suivante.
- Les noms d'utilisateur utilisent l'alphabet latin dans toutes les langues, pour que tout le monde puisse les lire et les taper.

## Nom affiché

<Tip id="names.display">

Le nom affiché est facultatif. Si vous l'activez, il apparaît à la place de votre nom d'utilisateur à côté de vos avis. Il peut être dans n'importe quelle langue et n'a pas besoin d'être unique.

</Tip>

## Nom de fournisseur et adresse de votre page

<Tip id="names.provider">

Quand vous proposez un GPU, les locataires voient votre nom de fournisseur, jamais votre nom d'utilisateur. Votre page de fournisseur se trouve à gpuflow.app/marketplace/provider/ suivi de l'adresse de votre page. Chaque compte démarre avec un nom de fournisseur aléatoire, comme « Quiet Falcon », que vous pouvez changer quand vous voulez.

</Tip>

- Votre nom de fournisseur et l'adresse de votre page ne sont pas liés à votre nom d'utilisateur ni aux avis que vous écrivez comme locataire.
- Votre page de fournisseur montre vos annonces, votre niveau de fournisseur et les avis des locataires.

## Changer vos noms

<Tip id="names.changes">

Vous pouvez changer votre nom d'utilisateur et l'adresse de votre page une fois tous les %names.changeDays% jours. Un ancien nom d'utilisateur ou une ancienne adresse reste réservé pour vous pendant %names.oldNameHoldDays% jours, pour que personne d'autre ne puisse le prendre, et les liens vers l'ancienne adresse continuent de fonctionner pendant ce temps.

</Tip>

## Ce qui n'est jamais affiché

- Votre adresse e-mail.
- Votre vrai nom, y compris celui du compte Google ou GitHub avec lequel vous vous connectez.
- Votre photo de profil Google ou GitHub. Tout le monde a la même icône neutre.
- Quel nom de locataire et quel nom de fournisseur appartiennent au même compte.
