## GPUFlow 是什麼

GPUFlow 是一個市集，讓人按小時向其他人租用 GPU。

- **租用者**用信用卡儲值額度，挑一張 GPU，就會拿到一組 API 金鑰。任何支援 OpenAI API 的應用程式或程式碼都能使用這組金鑰。
- **提供者**在一台裝有 GPU 的 Linux 電腦上執行一條指令，設定每小時價格，收入會匯到自己的銀行帳戶。
