## 錢如何到您手上

<Steps>

1. **租用結束**。租用者支付實際使用的時間。GPUFlow 收取 12%，其餘 88% 歸您。
2. **您的收益會暫扣 7 天**。這筆收益會顯示在 **儀表板 → 支付** 的 **暫扣收益** 中。如果您的帳戶註冊未滿 30 天，暫扣期為 14 天。暫扣是為了防範信用卡盜刷和付款爭議。
3. **收益變成可提領**。暫扣期結束後，收益會移到 **可提領**，您也會收到通知。
4. **您提領款項**，透過我們的付款合作夥伴 Stripe 匯到您的銀行帳戶。

</Steps>

您也可以用收益來租用其他 GPU。用信用卡購買的額度可以消費，但不能提領。

## 設定提領（只需一次）

您需要一個已驗證的電子郵件地址，以及一個 Stripe 收款帳戶。Stripe 會驗證您的身分，並詢問您的銀行資料。整個過程只需幾分鐘。

<Steps>

1. 打開 **儀表板 → 支付**。
2. 在 **提領** 下方，選擇您居住或公司登記所在的國家。
3. 點擊 **透過 Stripe 設定提領**，依照 Stripe 的步驟操作。請準備好身分證件和銀行資料。
4. 完成後，Stripe 會把您帶回 GPUFlow。

</Steps>

<Image src={setup} alt="「提領」區塊：國家清單和「透過 Stripe 設定提領」按鈕已標示出來" />

Stripe 有時會先審核您的資料。通常只需幾分鐘，有時需要一兩天。如果還有步驟沒完成，您會看到 **在 Stripe 繼續設定**。

**支援提領的國家**：美國、加拿大、英國、瑞士，以及歐洲經濟區：奧地利、比利時、保加利亞、克羅埃西亞、賽普勒斯、捷克、丹麥、愛沙尼亞、芬蘭、法國、德國、希臘、匈牙利、冰島、愛爾蘭、義大利、拉脫維亞、列支敦斯登、立陶宛、盧森堡、馬爾他、荷蘭、挪威、波蘭、葡萄牙、羅馬尼亞、斯洛伐克、斯洛維尼亞、西班牙和瑞典。

## 提領

<Steps>

1. 打開 **儀表板 → 支付**。
2. 在 **提領** 下方輸入金額，或保留已自動填入的全部金額。
3. 查看下方那一行：它會顯示 $2.50 的手續費，以及您實際會收到的金額。
4. 點擊 **提領**。

</Steps>

<Image src={cashout} alt="「提領」區塊，金額欄位和「提領」按鈕已標示出來" />

- **最低金額**：每次提領 $25。
- **手續費**：每次提領 $2.50，不論金額多少。減少提領次數可以省下手續費。
- 款項會以美元匯到您的 Stripe 收款帳戶，再由 Stripe 撥入您的銀行帳戶。
- 款項送出時，您會收到電子郵件和通知。如果提領未成功，全部金額會退回您的餘額。
- 隨時可以透過 **在 Stripe 管理收款資料** 更改銀行資料。

## 如果租用者對信用卡付款提出爭議

有時租用者會要求銀行撤銷一筆信用卡付款。發生這種情況時，GPUFlow 會從該租用者的租用中，扣回**仍在暫扣期**的收益，您也會收到電子郵件通知。如果爭議結果對我們有利，這些收益會退還給您。已經結束暫扣期的收益不受影響。

<Aside type="note">
您的收益屬於所得。如何課稅取決於您居住的地方。如果不確定，請諮詢稅務顧問。
</Aside>
