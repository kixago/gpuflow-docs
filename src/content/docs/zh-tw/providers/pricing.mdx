租用者選擇您的 GPU 還是別人的，價格是最大的原因。以下說明您能拿到多少、執行成本是多少，以及和您同級的 GPU 目前的租價。

## 您能拿到多少

您設定每小時價格。租用者依使用時間支付這個價格。**GPUFlow 收取 12%，您拿到 88%**。

| 您的每小時價格 | 您每小時的收入 | 每天 8 小時、持續 30 天 |
| --- | --- | --- |
| $0.10 | $0.088 | $21.12 |
| $0.20 | $0.176 | $42.24 |
| $0.35 | $0.308 | $73.92 |
| $0.50 | $0.44 | $105.60 |

最後一欄假設您的 GPU 每天被租用 8 小時。實際使用量取決於您的價格、您選擇的模型，以及您在線的頻率。

## 執行成本是多少

主要成本是電費。您可以在一分鐘內算出來：

<Steps>

1. 在 GPU 忙碌時打開 **我的機器**。卡片上會以瓦特顯示它的 **功耗**。
2. 除以 1,000 換算成千瓦。350 W 就是 0.35 kW。
3. 乘以您每度電（kWh）的電價（可在電費帳單上找到）。

</Steps>

範例：0.35 kW × 每度 $0.15 = **每小時 $0.053**。您每小時的收入應該要遠高於這個數字。

大型雲端公司的資料中心 GPU 收費高得多。例如，AWS 上一張 NVIDIA L4 每小時大約 $0.80。但來到 GPUFlow 這類市集的租用者，會拿您和上表的價格比較，而不是和 AWS 比較。

<Aside type="note" title="為什麼要從區間的下半部開始">
在上述大多數網站上，租用者可以使用整台機器。在 GPUFlow 上，他們是透過 API 使用您的 AI 模型。這對他們來說比較簡單，但能做的事也比較少，所以請把價格定在區間的下半部，至少在您接到頭幾筆租用之前這樣做。
</Aside>

## 上架表單上的價格條

當您在 **上架 GPU** 或 **編輯** 中輸入小時費率時，欄位下方會有一條價格條，顯示您的價格落在哪裡：

<Image src={bar} alt="「小時費率」欄位下方的價格條，顯示此價格對這款 GPU 來說屬於常見價格" />

- **綠色區段「其他租賃網站」**：您的 GPU 型號在其他租用網站上的一般價格區間，資料來自上表。
- **藍色線段「GPUFlow 上該型號的其他上架」**：GPUFlow 上相同 GPU 型號其他上架資訊的平均價格，以及它們的最低價和最高價。只有在有其他上架資訊時才會顯示。
- **橘色標記**：您的價格。價格條下方那一行會顯示 **價格偏低**、**常見價格** 或 **價格偏高**，最後一行則會告訴您扣除 12% 費用後每小時的收入。

如果您的 GPU 不在上表中，而且 GPUFlow 上也還沒有人上架同款 GPU，價格條就無法比較。請以表中最接近的顯示卡作為參考。

## 決定價格：一個簡單的方法

<Steps>

1. **從低價開始**。在您 GPU 的價格區間中，選擇下三分之一的價格。以 RTX 4090 來說，大約是 $0.30 – $0.35。
2. **保持在線**。租用者無法租用離線的 GPU。您在線的時數，比幾分錢的差價更重要。
3. **一週後再檢查一次**。
   - 大部分時間都有人租？把價格調高 $0.02 – $0.05。
   - 完全沒人租？把價格調低 $0.02 – $0.05，並確認描述中寫了您的模型。
4. **每月檢查一次**。其他網站的價格會變動。請在 **我的 GPU → 編輯** 中調整您的價格。

</Steps>
