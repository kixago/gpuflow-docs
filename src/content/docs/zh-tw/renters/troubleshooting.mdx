## API 錯誤

出問題時，API 會回傳一個錯誤代碼。請找出回應中的 `code`：

```json
{ "error": { "message": "...", "type": "server_error", "code": "provider_offline" } }
```

| 狀態碼 | `code` | 意思 | 怎麼處理 |
| --- | --- | --- | --- |
| 401 | `invalid_api_key` | 金鑰遺漏、打錯、已被 **新金鑰** 取代，或租用已結束。 | 重新複製金鑰。確認標頭是 `Authorization: Bearer gfk_…`。如果租用已結束，請開始新的租用。 |
| 400 | `invalid_body` | 您送出的內容不是有效的 JSON。 | 檢查引號和逗號。[使用您的 API 金鑰](/zh-tw/renters/api-quickstart/)中的範例是很好的起點。 |
| 503 | `provider_offline` | 提供者的機器目前離線。 | 等一分鐘再試。如果離線持續 10 分鐘，租用會自動結束，您只需支付到離線為止的費用。 |
| 503 | `relay_unreachable` | GPUFlow 無法連上通往該機器的連線。 | 稍後再試。如果一直發生，請開一張客服工單。 |
| 502 | `provider_error` | 機器沒有回傳任何內容。 | 再試一次。如果一直發生，請回報這筆租用。 |
| 503 | `provider_unbound` | 您的金鑰沒有連結到任何 GPU。 | 請開一張客服工單。 |

**「model … not found」**：您要求的模型不在這台機器上。請執行[使用您的 API 金鑰](/zh-tw/renters/api-quickstart/)中的 `/v1/models` 檢查，並使用查到的名稱。

## 儲值額度

| 訊息 | 解決方式 |
| --- | --- |
| 儲值前請先驗證您的電子郵件地址。 | 打開 GPUFlow 寄來的郵件，點擊裡面的連結。沒收到郵件？點擊儀表板上黃色橫幅中的 **重新寄送郵件**，並檢查垃圾郵件資料夾。 |
| 請輸入 $10 至 $500 之間的金額。 | 每次儲值金額必須介於 $10 至 $500。 |
| 付款已取消，未產生任何扣款。 | 您在付款前離開了 Stripe 頁面。請再試一次。 |
| 您已經付款，但額度還沒出現 | 等一分鐘後重新整理頁面。10 分鐘後還是沒有？請開一張客服工單。 |

## 開始租用

| 訊息 | 解決方式 |
| --- | --- |
| 額度不足：需要 … | 儲值額度，或減少租用時數。 |
| 此 GPU 的機器目前離線。 | 選擇其他 GPU，或點擊它卡片上的 **上線時通知我**，機器恢復上線時您會收到電子郵件。 |
| 請選擇 … 至 … 小時。 | 每張 GPU 都有自己的最短和最長時數。請選擇介於兩者之間的數字。 |
| 這是您自己的上架資訊。 | 您不能租用自己的 GPU。 |
| 嘗試次數過多。請一小時後再試。 | 請等一小時。這項限制可以防止失控的指令碼影響帳戶。 |

## 還是無法解決？

請到 [gpuflow.app/support](https://gpuflow.app/zh-TW/support) 開一張工單。如果問題和某一筆租用有關，請使用它旁邊的 **回報問題**，這樣我們就知道是哪一筆。請附上錯誤 `code`、發生時間，可以的話也附上您執行的指令或程式碼（**不要附上您的 API 金鑰**）。
