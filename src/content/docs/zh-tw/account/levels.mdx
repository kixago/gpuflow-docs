您有兩個等級，一個用於租用，一個用於提供，各自有自己的點數。租用者會在您的上架資訊和提供者頁面上看到您的提供者等級。您的租用者等級顯示在您的評論旁，您租用的提供者也看得到。兩個等級永遠不會同時顯示。您的儀表板會在 **你的等級** 中顯示兩者以及最近的點數。

## 點數如何運作

<Tip id="levels.points">

點數來自已完成的付費租用和評價。租用者和提供者每付費一小時都會獲得點數，每次租用最多 %points.maxPerRental% 點，評價也會增加或減少點數。每次變動都有紀錄，所以您的總點數隨時可以逐筆說明。

</Tip>

| 發生的事 | 租用者 | 提供者 |
| --- | --- | --- |
| 一次付費租用結束 | 每付費一小時 +%points.perPaidHour%，最多 %points.maxPerRental% | 每付費一小時 +%points.perPaidHour%，最多 %points.maxPerRental% |
| 您評價了對方 | %points.ratingGiven% | %points.ratingGiven% |
| 收到評論：5 / 4 / 3 / 2 / 1 星 | — | %points.stars5% / %points.stars4% / %points.stars3% / %points.stars2% / %points.stars1% |
| 提供者願意 / 不願意再次租給您 | %points.thumbsUp% / %points.thumbsDown% | — |
| 整個租用期間機器都保持連線 | — | %points.onlineWholeRental% |
| 租用期間機器離線 | — | %points.machineOffline% |
| 您的一筆信用卡付款遭到爭議 | %points.cardDispute% | — |
| 您的評論因濫用遭工作人員移除 | %points.reviewHidden% | — |

### 不計點數的情況

- 付費時間不足 %points.minPaidMinutes% 分鐘的租用。
- 同一租用者和提供者之間每月超過 %points.pairMonthlyCap% 次的租用。只有前 %points.pairMonthlyCap% 次計點。
- 正在審查的租用（見下文）。

## 等級

<Tip id="levels.levels">

共有 %levels.max% 個等級。點數一達到下一個等級就會升級。即使一段時間沒有使用，等級也不會下降。只有點數低於您下一級的門檻時才會降級，所以一次不好的租用不會讓等級反覆升降。

</Tip>

| 等級 | 所需點數 |
| --- | --- |
| 1 | %levels.thresholds.0% |
| 2 | %levels.thresholds.1% |
| 3 | %levels.thresholds.2% |
| 4 | %levels.thresholds.3% |
| 5 | %levels.thresholds.4% |
| 6 | %levels.thresholds.5% |
| 7 | %levels.thresholds.6% |
| 8 | %levels.thresholds.7% |
| 9 | %levels.thresholds.8% |
| 10 | %levels.thresholds.9% |

## 等級解鎖的權益

<Tip id="levels.perks">

等級 %levels.searchLevel% 以上的提供者，在價格或評分相同時會排在其他提供者前面；等級 %earnings.shortHoldLevel% 以上、且帳戶註冊滿 %earnings.shortHoldMinAgeDays% 天的提供者，收益在 %earnings.shortHoldDays% 天後即可使用，而不是 %earnings.holdDays% 天。開啟兩步驟驗證的租用者，從等級 %credits.topupLevel1% 起單次最多可儲值 %credits.topupLevel1Usd%，從等級 %credits.topupLevel2% 起最多 %credits.topupLevel2Usd%。

</Tip>

儀表板上的 **你的等級** 會列出下一個等級解鎖的內容。之後可能會增加更多權益。

## 新帳戶

<Tip id="levels.newAccounts">

一次租用的點數要等兩個帳戶都註冊滿 %points.newAccountDays% 天後才會計入。在那之前，它們會在 **你的等級** 中顯示為保留，並附上計入日期。

</Tip>

## 審查期間保留的點數

<Tip id="levels.review">

有時 GPUFlow 會更仔細地審查一次租用，例如兩個帳戶看起來有關聯，或某筆付款看起來不尋常。審查期間，這次租用的點數不會計入，兩個帳戶都無法升級。大多數審查會自動結束，審查通過後點數就會加上。

</Tip>

租用本身不受影響。如果您認為審查有誤，請[提交支援單](https://gpuflow.app/zh-TW/support)。
