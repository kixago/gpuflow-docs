GPUFlow 會把您租用時使用的名稱和您以提供者身分使用的名稱分開，所以沒有人能看出兩者屬於同一個人。您的電子郵件地址和真實姓名永遠不會顯示。所有名稱都在 **帳戶設定 → 你的名稱** 中設定。

## 使用者名稱

<Tip id="names.username">

您用使用者名稱登入（也可以用電子郵件地址），在您開啟顯示名稱之前，它也是顯示在您評論旁的名稱。長度為 %names.usernameMin% 到 %names.usernameMax% 個字元：英文字母 a 到 z、數字，以及夾在中間的單一句點、底線或連字號。大小寫不同不算不同的名稱。

</Tip>

- 您在建立帳戶時選擇使用者名稱。如果用 Google 或 GitHub 註冊，會在下一步選擇。
- 所有語言的使用者名稱都使用拉丁字母，方便每個人閱讀和輸入。

## 顯示名稱

<Tip id="names.display">

顯示名稱是選填的。開啟後，您評論旁顯示的是它，而不是使用者名稱。它可以使用任何語言，也不必是唯一的。

</Tip>

## 提供者名稱和頁面網址

<Tip id="names.provider">

您上架 GPU 後，租用者看到的是您的提供者名稱，永遠看不到使用者名稱。您的提供者頁面位於 gpuflow.app/marketplace/provider/ 後接您的頁面網址。每個帳戶一開始都有一個隨機的提供者名稱，例如「Quiet Falcon」，您可以隨時更改。

</Tip>

- 您的提供者名稱和頁面網址與您的使用者名稱、以及您以租用者身分寫的評論都沒有關聯。
- 您的提供者頁面會顯示您的上架資訊、提供者等級和租用者的評論。

## 更改名稱

<Tip id="names.changes">

使用者名稱和頁面網址每 %names.changeDays% 天可以更改一次。舊的使用者名稱或頁面網址會為您保留 %names.oldNameHoldDays% 天，其他人不能使用，在這段期間指向舊頁面網址的連結也仍然有效。

</Tip>

## 永遠不會顯示的內容

- 您的電子郵件地址。
- 您的真實姓名，包括您用來登入的 Google 或 GitHub 帳戶上的姓名。
- 您在 Google 或 GitHub 上的大頭貼。所有人顯示的都是同一個簡單圖示。
- 哪個租用者名稱和哪個提供者名稱屬於同一個帳戶。
